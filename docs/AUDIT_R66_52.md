## Находки

### P2-1. Офлайн-фолбэк SW игнорирует раздел сайта
`sw.js:86` — при неудаче сети навигация получает `caches.match('/index.html')`.
Для офлайн-открытия непосещённого `/en/…` игрок получит RU-лендинг, а для
`/game/…` — лендинг вместо игры (точное совпадение в кэше спасает только
ранее посещённые URL). Рекомендация (5 строк в sw.js):
```js
var fb = url.pathname.indexOf('/game/') === 0 ? '/game/'
       : url.pathname.indexOf('/en/') === 0 ? '/en/' : '/index.html';
return cached || caches.match(fb);
```
Цена: повышение site-cache до v101 (по протоколу) + актуализация SW-ожиданий 20 наборов.
→ ВНЕДРЕНО в патче 66.53 (приказ владельца №1; дополнительно добавлен второй эшелон
`caches.match('/')` — ключ `/index.html` возникает редко, посетители попадают на `/`).

### P2-2. EN-версия 404 почти полностью русская
`en/404.html`: `lang="en"` стоит, но контент — «Свиток утерян», «Страница,
которую вы ищете, исчезла из летописей…», «← На главную»; по-английски только
«Play the demo». Рекомендация: перевести заголовок/текст/кнопку
(«The scroll is lost», «Back to the front page» и т.п.), титул
«404 — The scroll is lost | The Chronicles of Ruthenia».
→ ВНЕДРЕНО в патче 66.53 (приказ владельца №2), с уточнением: GitHub Pages отдаёт
на /en/…-пути корневой 404.html (проверено curl'ом прода), поэтому EN-тексты
добавлены и в корневой 404.html (inline-скрипт: pathname /^\/en(\/|$)/ → подмена
текстов/lang/titула), а en/404.html переведён полностью (прямая ссылка).

### P2-3. Бренд-титул игры не локализован (титульный экран EN)
`TitleScene.js:57` и `PreloadScene` рисуют «ЛЕТОПИСИ РУСИ» независимо от языка,
при том что подзаголовок, все кнопки меню, Инструкция/Настройки/Об игре/выбор
персонажа уже полностью переведены (проверено живыми скриншотами ?lang=en).
На EN-титуле бренд — единственное русское слово на экране. Рекомендация:
isEn() ? 'THE CHRONICLES OF RUTHENIA' : 'ЛЕТОПИСИ РУСИ' + формула размера под
длину EN-строки (26 символов против 13 — на мобильной ширине переполняет).
→ ВНЕДРЕНО в патче 66.52 (приказ владельца №2).

### P3-1. sitemap lastmod устарел
Оба `<lastmod>` = 2026-09-27; с тех пор вышли патчи 66.48–66.51 с изменением
обеих страниц. Рекомендация: обновлять lastmod в чек-листе каждого пуша
(или генерировать скриптом).

### P3-2. Нет ленмарка `<main>`
На лендинге header/nav/footer есть, обёртки `<main>` нет — скринридеры не
получают главную ориентир-зону. Рекомендация: обернуть основной контент
(секции после nav) в `<main>` на обеих версиях.

### P3-3. manifest.json моноязычный
name/short_name/description/lang — только RU: PWA, установленная с EN-лендинга,
получит русское имя приложения. Рекомендация: /en/manifest.json + подмена
`link[rel=manifest]` на EN-версии (или оставить как есть — эстетика).

### P3-4. Пустые src у пары img-заготовок
Два `<img src="" alt="">` (шаблон лайтбокса в gallery.js и заготовка в figure)
— безвредно (контейнер скрыт), но чистота DOM лучше: рендерить img при
открытии лайтбокса или выставлять src в JS.
→ ВНЕДРЕНО в патче 66.55: img убраны из innerHTML-шаблонов обоих лайтбоксов
(gallery.js + lightbox.js — второе место, не названное в аудите явно) и
создаются через createElement без атрибута src; реальные src/alt выставляют
функции открытия (openLightbox / slbShow). Порядок DOM и стили сохранены.
