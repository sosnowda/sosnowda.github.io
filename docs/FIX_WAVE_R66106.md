# Волна В/С/Н frontier-аудита 66.104 + LCP-цель 2.5s — итерация 66.106

**Приказ владельца** (по реестру аудита 66.104): «реестр аудита 66.104 содержит ещё 57 находок
(24 В + 18 С + 15 Н) с готовыми направлениями фиксов — могу закрыть следующей волной по приказу.
Для цели LCP 2.5s следующие кандидаты: defer Яндекс.Метрики и self-host шрифтов».

Приказ исполнен: из 57 находок **закрыто 55**, 2 закрыты частично с задокументированной
траекторией (Н14, С1), плюс исполнено направление К6 → LCP (defer Метрики + self-host шрифтов).

## 1. LCP-цель 2.5s (направление К6)

### 1.1 Яндекс.Метрика — отложенная загрузка (RU+EN)
Было: синхронный инициализатор в `<head>` — скачивание `metrika/tag.js` и исполнение
вебвизора конкурировали с героем/шрифтами за критический путь.
Стало: инициализация **после `window.load`** внутри `requestIdleCallback` (таймаут-предохранитель
4000 мс, фолбэк `setTimeout`) — витрина отрисовывается первой, счётчик стартует с задержкой в долю
секунды (на статистику визитов не влияет: hit отправляется при инициализации счётчика).
**В19 закрыт тем же патчем**: `webvisor:false` — запись сессий (DOM, движения мыши) не является
«стандартным минимумом» данных. Возврат флага — осознанное решение владельца (одна строка).

### 1.2 Шрифты — самохостинг (RU+EN)
Было: рендер-блокирующий `<link rel="stylesheet" href="https://fonts.googleapis.com/css2?…">`
+ два preconnect на внешние хосты: DNS+TLS к googleapis, отдельный CSS, затем DNS+TLS к gstatic
за каждым woff2.
Стало: **19 woff2 в `assets/fonts/`** (Prata 400; PT Sans 400/700; PT Serif 400/700 × подмножества
cyrillic/cyrillic-ext/latin/latin-ext), `@font-face` в начале `styles.css` с исходными
`unicode-range` — браузер качает только используемые подмножества (реально 3–6 файлов, ~60–90 КиБ),
`font-display: swap` — текст не блокируется. Состав лиц бит-в-бит прежнему css2-запросу
(курсив снят ранее, 66.91). Хосты Google удалены из CSP (style-src/font-src).

### 1.3 Замеры (прод, Lighthouse 13.5.0 ×3 — методика 66.98)
- **prod RU mobile ×3: perf 99/100/100, FCP 1.00–1.43 c, LCP 1.28/1.52/1.80 c — медиана 1.52 c**
  (было 3.0 c в 66.103–66.104; снижение вдвое, цель 2.5s достигнута с запасом 40%);
  TBT 0.03–0.07 c, CLS 0.005, A11y 100, SEO 100, BP 73 (= Метрика, шум сертификатов песочницы;
  в браузере без MITM — 77).
- Локальная контрольная (HTTP/1.1 http.server): perf 89/87, LCP 3.19/3.41 — localhost ставит
  шрифты/картинку в одну HTTP/1.1-очередь того же origin; на проде (HTTP/2) эффект полный.
- **Гейт lighthouserc ужесточён 3500 → 2500** — цель владельца теперь не «цель», а бюджет.
