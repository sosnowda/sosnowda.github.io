## 1. F1 — справка игры вместо браузера

**Диагноз.** Игровые окна «❓ Помощь» существуют во всех сценах с раунда 32 (Title, Village, Interior, Forest, Fork, Location, Combat, Apiary — keydown-F1). Но preventDefault нигде не вызывался, и браузер ПОВЕРХ игры открывал собственную справку. Дополнительное открытие: точка входа игры — inline-лоадер `game/index.html`, который импортирует сцены НАПРЯМУЮ; `src/main.js` на странице вообще не выполняется (выяснено по resource-timing и synthetic-событию: правка в main.js не давала эффекта).

**Фикс.** Глушитель F1 (window keydown → preventDefault для e.code/e.key/e.keyCode 112) добавлен в `game/index.html` ДО старта загрузчика сцен; в `src/main.js` — идиоматичный дубль (window-листенер + Phaser `addKeyCapture('F1')`) для сред, где main.js выполняется. preventDefault не мешает обработчикам Phaser — событие всплывает дальше.

**Проверка:**
- синтетический cancelable `KeyboardEvent('keydown', {code:'F1'})` на window → `defaultPrevented = true` (до фикса — false);
- реальное нажатие F1 (CDP Input) → probe-листенер: `defaultPrevented = true`;
- окно «❓ Помощь» открывается: Title (текст «🎯 ЦЕЛЬ ИГРЫ…», «F1 — окно помощи», кнопка «Закрыть») и Village (диалог «❓ Помощь», кнопка «1. Понятно» закрывает, busyDialog сбрасывается);
- скриншот /tmp/qa56-f1-help.png.

## 2. «Крестики» по центру строений

**Диагноз.** «Крестики» — золотые маркеры-искры `particle_spark` 20×20 над дверью КАЖДОГО из 17 зданий (введены раундом 37 как маркер входа; пользовательски читаются как крестики по центру строений). Фасады-спрайты проверены визуально — крестиков в текстурах нет.

**Фикс.** VillageScene: блок создания `doorMarker` удалён; `this.doors` сохраняет {x, y, interiorId} (якоря птиц у дверей и входы работают). Искры над сундуками (игровая подсказка лута) и маркер «ВЫХОД ▶» у ворот сохранены сознательно.

**Проверка:** деревня → `doors.length = 17`, `doors.filter(d => d.marker).length = 0`; в сцене остался ровно 1 `particle_spark`-объект (ворота), на позициях дверей — 0 объектов. Скриншот /tmp/qa56-village-desktop.png — над домами чисто.
