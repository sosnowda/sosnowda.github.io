## 3. П.3 «При убийстве НПЦ игроком: деревня и все НПЦ −50, супруга/дети убитого — до −100» — ✅ ПРОЙДЕН

**Сценарий вживую:** Тарас (пахарь, жена Фёкла + семеро детей) разозлён → бой в интерьере (`npcId: 'beekeeper1_hostile'`) → герой побеждает (Меч: попадание! Урон 5) → поп-ап «☠ Кровная вина!» → «В деревню!».

| Проверка | Ожидание | Результат |
|---|---|---|
| Репутация деревни | −50 (прямая запись, без множителей ×1.2) | **−50** ✅ |
| ВСЕ прочие жители (тавернщик, священник, кузнец, староста…) | −50 каждому | все **−50** ✅ |
| Супруга убитого (Фёкла) | ДО −100 | **−100** ✅ |
| Дети убитого (kid1…kid7) | ДО −100 | все **−100** ✅ (unit: kinNames = 8) |
| Убитый | флаг смерти | `q.npcKilled.beekeeper1 = true` ✅, его репутация −100 |
| Поп-ап | честный текст о цене крови | «Ты убил Тарас. Вся деревня в ужасе: репутация… упала на 50!… смываются только вирой у старосты» |
| Дом убитого | «тишина», без кнопок | **«🕯 Здесь стоит тишина… / погиб(ла) от твоей руки / Дом опустел, вещи прикрыты холстиной / Деревня шепчется о кровной вине»**; кнопки диалога отсутствуют, живая Фёкла (вторая фигура) осталась |
| Улица деревни | убитый не выходит | `rebuildStreetNpcs` пропускает убитых (`isNpcKilled`) |
| Баннер цели | ведёт к вире | «Кровная вина на тебе. Староста может помирить за виру.» |
| НПЦ-убийство ≠ тестовые бои | вор/разбойник с тракта НЕ считаются убийством | ветка `_hostile` — только бои из интерьеров |

*Файлы: reputation.js (`applyNpcMurderConsequences`), CombatScene.js (`endCombatVictory`), VillageScene.js (улица), InteriorScene.js (дом).*

## 4. П.4 «Если на игрока напал НПЦ — можно сбежать; повторно он не нападает сразу» — ✅ ПРОЙДЕН

**Сценарий вживую:** бой с Тарасом → «🏃 Бежать» → **бросок 29 — успех** → возврат в деревню.

| Проверка | Ожидание | Результат |
|---|---|---|
| Побег из боя с НПЦ | работает (проверка Уклонения) | успех, −2 действия, лог «Побег из боя с разгневанным жителем» |
| Перемирье | НПЦ не нападает сразу | `npcTruceUntil.beekeeper1 = now + 720` (**ровно 12 ч**) ✅ |
| Разговор в перемирье | отказ БЕЗ нападения | `checkNpcWillingToTalk`: `willAttack: false`, «Уходи! Я тебя ненавижу… но староста велел крови сегодня не проливать.» |
| После 12 ч | шансы нападения возвращаются | перемирье истекло; за 500 попыток нападение произошло (шанс −100 → 50%) ✅ |
| Бои с вор/разбойник | прежняя логика (вор затаился и т.д.) | не тронута (ветки `isThiefFight` сохранены) |

*Файлы: CombatScene.js (`flee`), reputation.js (`setNpcTruce`/`isNpcTruceActive` + ветка в `checkNpcWillingToTalk`).*

## 5. П.5+П.6 «Староста мирит за виру по Судебнику; после выплаты репутация НПЦ → +30» — ✅ ПРОЙДЕН

**Расчёт виры (Русская Правда, Пространная редакция + Судебник 1497):**

| Категория | Ставка | В деньгах игры | При −100 (разбой без свады) |
|---|---|---|---|
| Свободный муж | вира 40 гривен + продажа 20 д. | **100 д.** | **200 д.** |
| Женщина или отрок (до 18) | полувирье 20 гривен + продажа 20 д. | **60 д.** | **120 д.** |

**Unit-проверки:** вира кузнеца при −100 = 200 ✅; Фёклы (женщина, −50) = 60 ✅; Ивашки (отрок 14, −50) = 60 ✅; при недостатке денег — отказ без списания ✅.

**Вживую (после убийства Тараса):**
| Проверка | Результат |
|---|---|
| Опция в диалоге старосты | **«1. 🤝 Просить мира (вира по Судебнику)»** — первая в списке (есть враги) |
| Хаб виры | текст Судебника + список: «Фёкла (120 д.)» + дети (по 120 д.) — до 6 кнопок; убитый Тарас в списке ОТСУТСТВУЕТ (мёртвых не мирят) |
| Оплата Фёкле | деньги 311 → **191** (−120 д.) |
| Репутация НПЦ после виры | **ровно +30** (было −100) ✅ |
| Поведение НПЦ | разговаривает снова (`canTalk: true`), больше не враждебен |
| Журнал | «🤝 Примирение у старосты: выплачена вира 120 д. за Фёкла (вира 40 д. + продажа 20 д., за разбой без свады — вдвое). Репутация Фёкла теперь +30.» |
| Повтор | «🤝 Просить мира ещё» → возврат в хаб; когда мирить некого — «На тебя никто больше не в ярости» |

*Файлы: reputation.js (`getHostileNpcs`/`calculateVira`/`payViraToElder`), dialogue.js (узлы `vira_hub`/`vira_pay` + опция в `a`).*
