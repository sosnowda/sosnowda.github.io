## 2. Найденные и ИСПРАВЛЕННЫЕ дефекты

### 2.1 Незакрытый `<div>` в секции «Ролевая система BRP» (index.html + en/index.html)
`<div class="container">` (стр. ~347) не закрывался перед `</section>` (стр. ~416) — браузер компенсировал ошибку, но вёрстка была валидно сломанной.
**Фикс:** добавлен `</div><!-- /container -->` перед `</section>`.

### 2.2 Лишний `</div>` в подвале (index.html + en/index.html)
После блока донатов стоял лишний `</div>` (контейнер подвала уже был закрыт выше) — компенсирующий артефакт ошибки 2.1.
**Фикс:** удалён. После исправлений: **0 ошибок вёрстки во всех трёх HTML**.

### 2.3 Шрифт Marcellus использовался, но не подключён (index.html ×9, en/index.html ×9)
Inline-стили заголовков секций/карт/плашек задавали `font-family:'Marcellus',serif`, однако в `<link>` Google Fonts подключены только Prata и PT Serif. Кроме того, Marcellus вообще не поддерживает кириллицу — даже при подключении заголовки рендерились бы фолбэком.
**Фикс:** все 18 вхождений заменены на подключённый кириллический антикв **Prata** (визуально тот же замысел: заголовки в антикве, а не системным serif).

## 4. Служебные находки (не дефекты)

- Строки с последовательностью `a[href` при выводе в некоторые терминалы отображаются как `aref` (съедается `[h` как ANSI-управляющая последовательность) — при первичном аудите это дало ложную тревогу «невалидный селектор». Фактическая проверка через `python` (содержит `a[href` = True, `aref` = False) подтвердила: селекторы в `main.js` корректны. Метод проверки зафиксирован для будущих аудитов.
- `<link rel="preload" as="image" href="assets/images/title.webp">` соответствует `<img src="assets/images/title.jpg">` в hero — двойной загрузки нет: браузер скачивает только webp-преплоад для LCP-кандидата; jpg остаётся фолбэком без preload. Оставлено как есть.
