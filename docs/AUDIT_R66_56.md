## Находки

### P3-1. Мёртвый hover-отклик бренд-бара (fund-bar)
styles.css:658 — единственный `.fund-bar:hover{background:…}` без `!important`;
styles.css:786 (средневековая тема) — `.fund-bar{background:… !important}`.
`!important` бьёт обычное объявление независимо от специфичности → hover-фон
никогда не применяется: полоска сбора средств не даёт курсорного отклика.
Рекомендация: в блоке 786 добавить парный
`.fund-bar:hover{background:linear-gradient(90deg,#B53925,#8B2C1A) !important;}`
(или пересобрать каскад без `!important`, подняв специфичность темы) и снять
кадр hover-состояния до/после. Заодно можно слить два блока `.fund-bar`
(657+786) в один — паттерн консолидации 66.49.

### P3-2. На 404-страницах нет CSP
Корневой 404.html и en/404.html не имеют meta CSP (лендинги и игра — имеют),
при этом корневой исполняет inline-скрипт локале-детекта (66.53). Сейчас
безвредно (страница статична, внешних данных не принимает), но защита должна
быть одинаковой на всех обслуживаемых HTML. Рекомендация: скопировать на обе
404-страницы CSP лендингов — `script-src 'self' 'unsafe-inline'` сохранит
работу детекта (проверить EN-подмену на стенде после правки).

### P3-3. Офлайн-фолбэк SW отвечает HTML на субресурсы
sw.js, catch-ветка network-first (66.53): фолбэк-цепочка применяется ко ВСЕМ
same-origin GET. При офлайне и промахе кэша js/css-запрос получит HTML-лендинг
→ MIME/Syntax-ошибка в консоли вместо честной сетевой ошибки. Сценарий редкий
(субресурсы посещённой страницы уже в рантайм-кэше), потому P3. Рекомендация:
фолбэк — только для `request.mode === 'navigate'`; прочие запросы —
`return cached;` (промах → естественный reject).

### P3-4. sitemap lastmod ведётся вручную и опережает факты
lastmod лендингов = 2026-10-01 проставлен в 66.54, тогда как коммиты датируются
2026-09-30 (дата на день «в будущем»); в 66.55 лендинговые js/modules снова
менялись, а lastmod не трогался. Для краулеров не вредно, но ручной процесс уже
даёт дрейф. Рекомендация: пункт «бамп lastmod» в чек-листе пуша либо
однострочный генератор (git log -1 --format=%ad → sitemap.xml).
