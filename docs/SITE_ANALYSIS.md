# Анализ сайта «Летописи Руси» — предложения по доработке

## Текущее состояние

Сайт (`sosnowda.github.io`) — одностраничный лендинг для презентации игры.
Состоит из: `index.html` (597 строк), `styles.css` (747 строк), `main.js` (151 строка).

### Что есть
- Средневековый стиль (пергамент, золото, киноварь)
- Hero-секция с заголовком и подзаголовком
- Карусель эпох с описанием периодов
- Карты Руси XV века (2 шт, с lightbox)
- Раздел BRP с интерактивным кубиком d100
- Раздел технологий
- Раздел персонажей
- Раздел демонстрации
- Раздел поддержки (Boosty, ЮMoney, VK и др.)
- Footer со ссылками
- PWA (manifest + service worker)
- SEO (sitemap, robots, JSON-LD)

## Предложения по доработке

### 1. Визуальные улучшения

#### 1.1. Параллакс-эффект на hero-секции
- Фоновое изображение движется медленнее контента при скролле.
- Создаёт ощущение глубины.

#### 1.2. Анимированный фон с частицами
- Золотые искры/перья, медленно опускающиеся вниз.
- Сейчас есть только в TitleScene игры, можно добавить и на сайт.

#### 1.3. Видео-фон в hero
- Короткое зацикленное видео средневековой деревни или леса.
- Альтернатива: CSS-анимация градиента (от заката к рассвету).

#### 1.4. Улучшенные карточки эпох
- Каждая эпоха — раскрывающаяся карточка с превью-изображением.
- При клике — подробное описание с временной шкалой.

#### 1.5. Анимация появления карт
- Карты появляются с эффектом «разворачивания свитка».
- Сейчас просто fade-in.

### 2. Контентные улучшения

#### 2.1. Раздел «Скриншоты игры»
- Галерея скриншотов из браузерного демо.
- Сетка 3×2 с lightbox.

#### 2.2. Раздел «Историческая справка»
- Короткие статьи о Руси XV века:
  - Быт крестьян
  - Военное дело
  - Религия и церковь
  - Торговля и деньги

#### 2.3. Раздел «FAQ»
- Часто задаваемые вопросы о проекте.

#### 2.4. Блог/Новости разработки
- Лента обновлений с датами.
- Возможность подписки (через Boosty).

#### 2.5. Раздел «Команда»
- Кто делает проект (даже если это один человек с AI).

### 3. Технические улучшения

#### 3.1. Оптимизация загрузки
- Lazy loading изображений (loading="lazy").
- WebP вместо JPG для карт (меньший размер).
- Preload критических ресурсов.

#### 3.2. Адаптивность
- Проверить и исправить мобильную версию.
- Гамбургер-меню на мобильных.
- Уменьшить размер шрифтов на маленьких экранах.

#### 3.3. Доступность (a11y)
- Добавить alt-тексты для всех изображений.
- ARIA-метки для интерактивных элементов.
- Контраст текста на тёмном фоне.

#### 3.4. Производительность
- Минифицировать CSS и JS.
- Inline critical CSS.
- Использовать CDN для шрифтов.

### 4. Функциональные улучшения

#### 4.1. Встроенное демо на главной
- Вместо ссылки «Играть в демо» — встроенный iframe с игрой.
- Кнопка «Открыть на весь экран».

#### 4.2. Сравнение «до/после»
- Слайдер, показывающий графику до и после доработки.

#### 4.3. Музыка на сайте
- Фоновая средневековая музыка с кнопкой включения.
- Использовать уже сгенерированные треки из игры.

#### 4.4. Счётчик поддержавших
- Показывать количество поддержавших на Boosty.

### 5. SEO и маркетинг

#### 5.1. Улучшить meta-теги
- Open Graph для соцсетей (уже есть, проверить).
- Twitter Card.
- Canonical URL.

#### 5.2. Структурированные данные
- VideoObject для промо-видео.
- SoftwareApplication для игры.

#### 5.3. Sitemap
- Обновить с учётом новых разделов.
