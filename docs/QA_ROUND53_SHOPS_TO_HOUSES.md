# QA раунда 53 — «Лавки → жилые дома»

Приказ владельца: *«"Лавка снеди выглядит отлично… Проверяю панель „Торговать"." — **удалить торговую и мясную лавки!** На место них поставить новый жилой дом! Дома нужны больше, чем ненужная лавка.»*

## Что сделано

| Было (раунд 51) | Стало (раунд 53) |
|---|---|
| Лавка снеди (`shop_food`, палатка `rural_shop_0`, Прасковья) | **Дом Прасковьи** (`grocer_house`, фасад `rurald_house_0` — светлый дом с голубой дверью и цветком из Rural_TileD) |
| Мясная лавка (`shop_meat`, палатка `rural_shop_2`, Потап) | **Дом Потапа** (`butcher_house`, фасад `rurald_house_1` — дом с каменной кладкой из Rural_TileD) |
| Лавка ремесленника (`shop_tools`, Аверьян) | **Без изменений** — палатка и кнопка «🛒 Торговать» сохранены |

### Ассеты
- Вырезаны 2 новых фасада из **Rural_TileD** (лист вскрывался впервые): `rurald_house_0.png` (192×182), `rurald_house_1.png` (192×223) — ручная разметка по сетке 96px + альфа-bbox.
- Сгенерированы **2 новых жилых интерьера** 1280×720 (`make_interiors_r53.py`, стиль r52v2: стены с карнизом, очаг слева под источником света `{x:90, y:0.48h}`, якоря «у стены / середина / передний план»):
  - `int_bg_grocer_house.jpg` — светлая хлебная горница: полки с караваями и сыром, батоны и растения на стене, очаг, комод, стол с пирогами и головкой сыра, кровать с тумбочкой, корзины, ковёр;
  - `int_bg_butcher_house.jpg` — столешня: колбасы и окорок на стене, разделочный стол с рядом нарезки, мешки, бочки, шкура медведя, кровать, икона в красном углу.
- Удалены из репо: `int_bg_shop_food.jpg`, `int_bg_shop_meat.jpg` (спрайты `rural_shop_0/2.png` остались на диске, но из загрузки BootScene сняты).

### Код
- `interiors.js`: `grocer_house` / `butcher_house` без `market` (панель «Торговать» исчезает автоматически — InteriorScene рисует её только при `interior.market`); BUILDINGS: `Дом Прасковьи` (18,1,w3) и `Дом Потапа` (18,6,w2).
- `VillageScene.js`: HOUSE_SPRITE_BY_ID (+`rurald_house_0/1`), FENCELESS обновлён (слобода по-прежнему без оград), эмблемы 🥖/🍖 переименованы по новым id.
- `BootScene.js`: `ruralKeys` → `['rural_shop_1','rural_house_0','rural_house_1','rurald_house_0','rurald_house_1']`; фоны `grocer_house`/`butcher_house`.
- `npcSchedules.js` / `npcPresence.js` / `npcNames.js`: Прасковья и Потап живут и работают дома («печёт караваи да пироги», «колет тушу»), `interiorId` жителей → новые дома, PLACE_NAMES очищены.
- `dialogue.js`: реплики Прасковьи («снедница: пеку дома… заходи на двор») и Потапа («заходи на двор…») переработаны под торговлю с крыльца; у Агафьи «к её **двору** носами идёт», у Горазда «Прасковья **печью обзаводится**» (было «палатку ладит»).
