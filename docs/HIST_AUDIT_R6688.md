## 1. Локации — вердикты по кадрам

### 1.1 Южный Тракт (01_tract_south.png) — ИСТОРИЧНО ✓
Грунтовое полотно с двумя колеями тележных колёс, задернованная середина,

Кадр подтверждён фактическим замером HUD (см. §2).

### 1.2 Пасека (02_apiary.png) — ИСТОРИЧНО ✓
КОЛОДНЫЕ ульи (дуплянки) — единственно возможная форма пасечного пчеловодства
XV в.; рамочные ульи появились в 1814 г. (Прокопович) — их нет. Избушка
пасечника, дымокур мирно тлеет (историчный приём успокоения пчёл), пчёлы
кружат над ульями и цветами. Карта ASCII-сеткой (apiary.js) — солиды
корректны, улей непроходим, наблюдение с соседнего тайла. Бортничество в
Тёмном лесу (борть «B», мёд/воск, укусы при провале — 66.74) — историчен:
бортные ухожаи — главный лесной промысел Руси XV в.

### 1.3 Тёмный лес (03_deep_forest.png) — ИСТОРИЧНО ✓

## 2. Фактический замер календаря (важная сверка)

Скриншотная проверка дат на глаз НЕНАДЁЖНА (мелкий кегль): кадр тракта был
первично прочитан как «лето 6283-е (1428)» — противоречие эре. Фактический
замер текста HUD из живой сцены (агент-браузер, eval):

```
📅 Пятница, 2-й день Липня, лето 6961-е (1453)   ☀️ Ясно   🕐 5-й час дня · заутреня отошла
```

Сверка формул RusTime.js: сентябрьская эра, eraYear = realYearAD + 5508
(январь–август); 1453 + 5508 = 6961 ✓. Народный месяцеслов: Липень = июль ✓.
Косые часы («5-й час дня») + церковный ориентир («заутреня отошла») ✓.
Диапазон старта: createRandomStartDate 1401–1500 (+5509) — границы XV века ✓.
Кадры: пасека «3 июля 6982 от С.М.» (=1473) ✓, ткачиха «6941» (=1432) ✓,
мельница «6912» (=1404) ✓, деревня «лето 6958-е (1450)» ✓ — ВСЕ даты
консистентны и историчны. Дни недели по-дореволюционному изводу
(«Понедѣльник», «Четвергъ») — стилистически верно.
