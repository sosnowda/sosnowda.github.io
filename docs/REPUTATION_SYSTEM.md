# Система репутации — Документация

## Обзор

Система репутации в «Летописях Руси» моделирует социальные отношения игрока с жителями деревни. Состоит из двух уровней:

1. **Деревенская репутация** (`villageRep`): общее мнение деревни об игроке (−100..+100).
2. **Личная репутация** (`npcRep[npcId]`): отношение конкретного NPC к игроку (−100..+100).

## Уровни репутации

| Значение | Уровень | Описание |
|----------|---------|----------|
| +100 | Свой человек | Игрок принят в деревню → **ВЫИГРЫШ** |
| +50..+99 | Друг деревни | Бонусы: скидки 20%, подарки, особые задания |
| +10..+49 | Уважаемый | Скидки 5-10%, увеличенные награды |
| 0..+9 | Нейтральный | Стартовое значение |
| −1..−29 | Нелюбимый | Нет бонусов, но NPC ещё говорит |
| −30..−49 | Нежеланный | NPC отказывается говорить |
| −50..−79 | Отверженный | NPC отказывается торговать, наценка 20% |
| −80..−100 | Враг | NPC имеет шанс напасть; староста выгоняет → **ПРОИГРЫШ** |

## Балансировка (п.12)

**Получить хорошую репутацию сложно, а падает она очень легко:**
- Положительные изменения умножаются на **0.7** (−30% к повышению).
- Отрицательные изменения умножаются на **1.2** (+20% к понижению).
- Личная репутация влияет на деревенскую только на **15%** от изменения.

## Действия и их влияние на репутацию

### Положительные действия

| Действие | Изменение | Примечание |
|----------|-----------|------------|
| Выполнение задания (лёгкое) | +4 личная, +2 деревня | × 0.7 = +2.8, +1.4 |
| Выполнение задания (среднее) | +7 личная, +3.5 деревня | × 0.7 = +4.9, +2.5 |
| Выполнение задания (тяжёлое) | +10 личная, +5 деревня | × 0.7 = +7, +3.5 |
| Угостить всех в таверне | +2 у каждого NPC, +3 деревня | Стоимость: 20 д. |
| Подарок принят | +1..+10 личная | Зависит от ценности подарка |
| Удачная похвала (крит) | +5 личная | Проверка Oratory |
| Удачная похвала (успех) | +2 личная | Проверка Oratory |

### Отрицательные действия

| Действие | Изменение | Примечание |
|----------|-----------|------------|
| Попрошайничество (1-2 раз) | −1 личная, −0.5 деревня | × 1.2 = −1.2 |
| Попрошайничество (3+ раз) | −2, −4, −8, −16 (экспонента) | Максимум −20 за раз |
| Ночное беспокойство | −3 личная | NPC разбужен ночью |
| Неудачная лесть (провал) | −1 личная | Проверка Oratory |
| Неудачная лесть (fumble) | −4 личная | Проверка Oratory |
| Агрессия (лёгкая) | −3 личная, −2 деревня | |
| Агрессия (средняя) | −6 личная, −4 деревня | |
| Агрессия (тяжёлая) | −12 личная, −8 деревня | |
| Угроза (успех) | −3..−5 личная | NPC обижен, но уступил |
| Угроза (провал) | −6 личная | NPC злится |
| Угроза (fumble) | −10 личная | NPC в ярости |
| Подарок отвергнут | −1 личная | NPC не принял подарок |

## Ночное беспокойство (п.2, п.3)

По ночам (с 19:00 до 4:00) NPC очень не любят, когда их будят:
- Отказ говорить + **−3 репутации**.
- **Исключения** (только ночью): срочное дело, опасность, выполненное задание.
- **Убрано из ночных исключений** (п.3): новый человек, подарок, поручение.

## Отказ говорить и торговать (п.1)

- При `npcRep ≤ −30`: NPC отказывается **говорить**.
- При `npcRep ≤ −50`: NPC отказывается **торговать**.
- При `npcRep ≤ −80`: NPC имеет **шанс напасть**.

## Нападение NPC (п.2, п.4)

При `npcRep ≤ −80`:
- **Шанс нападения** зависит от степени вражды:
  −80: 10%, −85: 15%, −90: 20%, −95: 25%, −100: 30%.
- Если не напал — всё равно отказывается говорить.

## Угрозы (п.7-10)

Игрок может **угрожать** NPC через кнопку «😠 Угрожать»:
- Используется навык **Intimidate**.
- При успехе — NPC выдаёт деньги (5-15 д.), но репутация падает.
- При провале — NPC отказывается и злится.
- При fumble — NPC может напасть.

### Реакции по полу (п.10)

| NPC → Игрок | Модификатор | Шанс нападения | Примечание |
|-------------|-------------|----------------|------------|
| Мужчина → Мужчина | −10 | 30% | Высокая вероятность отпора |
| Мужчина → Женщина | −15 | 15% | Мужчина сильнее реагирует, но реже нападает |
| Женщина → Мужчина | +10 | 0% | Женщина скорее уступит |
| Женщина → Женщина | −5 | 20% | Женщина может напасть на женщину |

### Историческая достоверность (п.11)

- Мужчины чаще дерутся с мужчинами.
- Мужчина редко поднимет руку на женщину.
- Мужчина сильнее реагирует на угрозы от женщины (оскорбление мужского достоинства).
- Женщины редко нападают на мужчин, но могут на женщин.

## Подарки (п.6, п.10)

Игрок может подарить NPC:
- **Деньги** (10 или 50 д.) — ценность = номинал × 0.5.
- **Любой предмет из инвентаря** — ценность = цена предмета × 0.5.

Шанс принятия подарка зависит от текущей репутации:
- При `npcRep ≥ 50`: шанс 87%.
- При `npcRep = 0`: шанс 70%.
- При `npcRep ≤ −30`: шанс 60%.

При успехе: `+1..+10` к репутации (зависит от ценности).
При неудаче: `−1` к репутации.

## Похвала (п.11)

Проверка навыка **Oratory**:
- **Крит**: +5 репутации.
- **Успех**: +2 репутации.
- **Провал**: −1 репутации.
- **Fumble**: −4 репутации.

## Бонусы высокой репутации (п.13)

| Репутация | Бонус |
|-----------|-------|
| +10..+29 | Скидка 5% на товары, +5% к наградам |
| +30..+49 | Скидка 10%, +12% к наградам, особые задания |
| +40+ | Кузнец может выковать оружие/доспех на заказ |
| +50+ | Скидка 20%, +25% к наградам, NPC дарит подарки |
| +50+ | Меньше падение репутации при просьбах (−50%) |
| +100 | Принят как свой → **ВЫИГРЫШ** |

## Изгнание и проигрыш (п.12)

При `villageRep ≤ −80`:
- Староста собирает сходку.
- Игрок изгнан из деревни.
- Переход в EndScene с финалом «ИЗГНАН».

## Выигрыш (п.13)

При `villageRep ≥ +100`:
- Староста объявляет игрока «своим».
- Переход в EndScene с финалом «ПРИНЯТ В ДЕРЕВНЕ».
