> `sosnowda.github.io` к приложению **GitHub Desktop** на Windows 10, и
> использовать его для обновления сайта (вместо командной строки).
>
> **Версия:** 1.0 (9 сентября 2026)

## 0. Что такое GitHub Desktop

**GitHub Desktop** — бесплатное приложение для Windows/macOS с графическим
интерфейсом для работы с Git. Позволяет:
- Клонировать репозитории (без команд `git clone`).
- Видеть изменённые файлы (diff).
- Делать коммиты (без `git commit`).
- Отправлять изменения на GitHub (без `git push`).
- Скачивать изменения с GitHub (без `git pull`).

**Преимущества для тебя:**
- ✅ Не нужно открывать командную строку (Git Bash / PowerShell).
- ✅ Визуальный интерфейс — всё мышкой.
- ✅ Бесплатно.
- ✅ Автосохранение паролей (один раз ввёл — больше не просит).

## 1. Установка GitHub Desktop

### Шаг 1. Скачать

1. Открой в браузере: https://desktop.github.com/
2. Нажми большую фиолетовую кнопку **«Download for Windows»** (или «Скачать для Windows»).
3. Скачается файл `GitHubDesktopSetup.exe`.

### Шаг 2. Установить

1. Дважды кликни `GitHubDesktopSetup.exe`.
2. Программа установится автоматически (без вопросов).
3. Откроется окно входа.

### Шаг 3. Войти в аккаунт GitHub

1. В окне GitHub Desktop нажми **«Sign in to GitHub.com»**.
2. Откроется браузер. Введи логин `sosnowda` и пароль (или авторизуйся).
3. Браузер спросит «Открыть GitHub Desktop?» — нажми **«Открыть»** (Open).
4. Вернёшься в приложение — оно покажет «Authenticated» (Авторизован).
5. Нажми **«Finish»** (Готово).

## 2. Подключение репозитория сайта

### Шаг 1. Клонировать репозиторий

1. В GitHub Desktop нажми **«File»** → **«Clone repository…»** (или `Ctrl+Shift+O`).
2. Откроется окно со списком твоих репозиториев.
3. В строке поиска введи `sosnowda.github.io`.
4. Выбери репозиторий `sosnowda/sosnowda.github.io` в списке.
5. В поле «Local path» (Локальный путь) выбери папку, например:
   ```
   C:\Users\DEIMOS\Documents\GitHub\sosnowda.github.io
   ```
   (или `C:\sosnowda.github.io` — любая папка на твоём выборе).
6. Нажми синюю кнопку **«Clone»** (Клонировать).

### Шаг 2. Проверить что файлы скачались

1. GitHub Desktop скачает файлы (5-10 секунд).
2. В левой панели появится репозиторий `sosnowda.github.io`.
3. В центре — список файлов (должен быть `index.html`).

### Шаг 3. Открыть папку в Проводнике

1. Нажми **«Show in Explorer»** (Показать в Проводнике) — кнопка в центре
   под списком файлов, или **«Repository»** → **«Show in Explorer»** (`Ctrl+Shift+F`).
2. Откроется Проводник с папкой `sosnowda.github.io`.
3. Ты увидишь файл `index.html` — это твой сайт.

## 3. Как обновлять сайт

### Сценарий: ты изменил `index.html` и хочешь обновить сайт

#### Шаг 1. Отредактировать файл

1. Открой папку `sosnowda.github.io` в Проводнике.
2. Нажми правой кнопкой по `index.html` → **«Открыть с помощью»** → **«Блокнот»**
   (или любой редактор: Notepad++, VS Code).
3. Внеси изменения (например, исправь текст).
4. Сохрани файл (`Ctrl+S`).

#### Шаг 2. Посмотреть изменения в GitHub Desktop

1. Открой GitHub Desktop.
2. Слева в списке репозиториев — `sosnowda.github.io`.
3. В центре ты увидишь изменённый файл `index.html` с жёлтой меткой **«Modified»**.
4. Кликни по нему — увидишь diff (что изменилось: зелёным — добавлено,
   красным — удалено).

#### Шаг 3. Сделать коммит (зафиксировать изменения)

1. В левом нижнем углу в поле **«Summary»** (Краткое описание) напиши:
   ```
   update: исправил текст на сайте
   ```
   (любое описание, что ты сделал).
2. Поле **«Description»** (Описание) — можно оставить пустым.
3. Нажми синюю кнопку **«Commit to main»** (Зафиксировать в main).

#### Шаг 4. Отправить на GitHub (Push)

1. После коммита наверху появится кнопка **«Push origin»** (Отправить).
2. Нажми её.
3. GitHub Desktop отправит изменения на GitHub (5-10 секунд).
4. Кнопка исчезнет — значит отправлено успешно.

#### Шаг 5. Дождаться обновления сайта

1. Открой https://github.com/sosnowda/sosnowda.github.io/actions
2. Найди последний workflow `pages-build-deployment`.
3. Дождись жёлтой точки → зелёной галочки (1-2 минуты).
4. Открой **https://sosnowda.github.io** — изменения появились!

## 4. Полный сценарий «Скачал новый index.html от меня — обновить сайт»

Если я (Super Z) обновил `website/index.html` в репозитории `ChroniclesRuthenia`,
и ты хочешь перенести эти изменения на свой сайт `sosnowda.github.io`:

### Шаг 1. Скачать новый index.html

1. Открой: https://github.com/sosnowda/ChroniclesRuthenia/blob/main/website/index.html
2. Нажми кнопку **«Raw»** над текстом кода.
3. Правой кнопкой → **«Сохранить как…»**
4. Сохрани как `index.html` (убедись что расширение `.html`).

### Шаг 2. Заменить файл в папке сайта

1. Открой Проводник.
2. Перейди в папку `sosnowda.github.io` (куда клонировал в §2).
3. Удали старый `index.html` (правой кнопкой → Удалить).
4. Скопируй новый `index.html` в эту папку.

### Шаг 3. Зафиксировать и отправить

1. Открой GitHub Desktop.
2. Увидишь `index.html` с меткой **Modified** (или может показать
   как удалён+добавлен — нормально).
3. В поле **Summary** напиши: `update: новая версия сайта`.
4. Нажми **«Commit to main»**.
5. Нажми **«Push origin»**.
6. Через 1-2 минуты — сайт обновлён на https://sosnowda.github.io

## 5. Дополнительные функции GitHub Desktop

### 5.1. Скачивать изменения с GitHub (Pull)

Если ты изменил файл прямо на сайте GitHub (через веб-интерфейс), и
хочешь, чтобы GitHub Desktop подхватил изменения:

1. Открой GitHub Desktop.
2. Нажми **«Fetch origin»** (Получить) — наверху справа.
3. Если есть изменения — кнопка поменяется на **«Pull origin»** (Стянуть).
4. Нажми её — изменения скачаются в локальную папку.

### 5.2. История коммитов

Вкладка **«History»** (История) — слева вверху:
- Видишь все коммиты с датами и описаниями.
- Кликни по коммиту — увидишь какие файлы изменились.

### 5.3. Откатить изменения (Undo)

Если внёс изменения в файл, но ещё НЕ сделал коммит:
1. Правой кнопкой по файлу → **«Discard changes»** (Отменить изменения).
2. Файл вернётся к последнему коммиту.

Если уже сделал коммит, но ещё НЕ отправил (Push):
1. Нажми **«Undo»** (Отменить) — внизу под коммитом.

### 5.4. Открыть в редакторе

**«Repository»** → **«Open in VS Code»** (или другой редактор) —
открывает папку в редакторе кода для удобного редактирования.

## 6. Типовые проблемы

### «Authentication failed» при Push

**Причина:** токен GitHub устарел или отозван.

**Решение:**
1. GitHub Desktop → **File** → **Options** → **Accounts**.
2. Нажми **«Sign out»** (Выйти).
3. Создай новый токен: https://github.com/settings/tokens → Generate new token (classic) → отметь `repo` → Generate.
4. В GitHub Desktop → **Sign in** → введи логин `sosnowda` и **новый токен** вместо пароля.

### «Merge conflict» (Конфликт слияния)

**Причина:** ты изменил файл локально, и одновременно изменил его на GitHub.

**Решение:**
1. GitHub Desktop покажет конфликт.
2. Выбери «Use my version» (Использовать мою версию) или «Use their version» (Их версию).
3. Сделай коммит.

### Файл не появляется на сайте после Push

1. Проверь https://github.com/sosnowda/sosnowda.github.io/actions — зелёная галочка?
2. Подожди 1-2 минуты (Pages пересобирается).
3. Нажми `Ctrl+F5` в браузере (жёсткое обновление, сброс кэша).

### GitHub Desktop не видит изменения файла

1. Убедись что ты сохраняешь файл (`Ctrl+S` в редакторе).
2. Нажми **«Refresh»** в GitHub Desktop (или `F5`).
