## 2. Анализ текущего состояния

### Сайт
✅ Сильное: RU/EN лендинг, шрифты Prata/PT Serif, свежие скриншоты, хроника
обновлений, PWA (manifest + SW v22, офлайн), интеграция DeepSeek через
сервер-функции, SEO (sitemap, og-теги).

⚠️ Слабое: скриншоты отстают от вида игры (после раундов 22–24 появились
портреты/бой лицом к лицу); трейлер mp4 в Git LFS не оформлен; 404-страница
только RU; hero-видео тяжёлое для мобильных.

### Игра
✅ Сильное: БРП-бой с реальными бросками (атака/уклонение/броня/щит/крит),
сюжет с вором (3-локационная погоня, следы, оглушение/убеждение), генератор
поручений (сроки по мировому времени), 10 NPC с расписаниями и уникальной
перекрашиваемой внешностью, погода, день/ночь, таверна (отдых/еда/тюк),
церковь (благословение), амбар (работа), часовня (молитва/пожертвование),
сохранения, настройки звука, тач-контролы, ~60 звуков + 6 музыкальных тем +
5 эмбиентов.

⚠️ Слабое (по убыванию заметности):
1. **Интерьеры — пустые коричневые прямоугольники** с декор-спрайтами; нет фонов.
2. **Эффекты боя примитивны** — пыль/круги вместо крови/искр; нет тряски камеры.
3. **Диалоги без «живости»** — нет плашки имени, анимации портрета, пергамент текстурно простой.
4. **Один звук шага** на все поверхности; погода без звуков (гром/ветер).
5. **Контент:** одна деревня; нет босса, подземелья, ярмарки; вор — единственный сюжетный враг.
6. **EN-локализация частичная** — диалоги thief.js/dialogue.js только RU.
7. **DPR-чёткость** — пиксель-арт мыл на ретине; спрайты 64px растянуты ×2.5.
8. HUD плоский — есть атлас RPG_GUI_v1, который не задействован.

## 3. План улучшений

### ФАЗА 1 — «Интерьеры и GUI» (следующий раунд, максимальный визуальный эффект)
1. **Фоны интерьеров** из art/backgrounds: `tavern.jpg` (192 КБ) в таверну,
   `village_blacksmith.jpg` (281 КБ) в кузницу, `kirche_inner.jpg` (1.8 МБ,
   лениво) в церковь, `Living Room.jpg`/`slums.jpg` в дома, `monastery.jpeg` в
   часовню. Рисовать под декор с виньеткой/затемнением 40% для читаемости
   текста и кнопок. Тяжёлые (>500 КБ) — ленивой загрузкой как музыка.
2. **Пергамент в диалоги**: `parchment_03.webp`/`parchment_04.webp` как фон
   createDialog (замена текущего procedural-пергамента) + плашка имени NPC
   (textribbon_01.webp) над текстом.
3. **VFX попаданий**: Effect_BloodImpact_1 (35 КБ) + blood_splat (27 КБ) при
   полном попадании; пыль оставить на промах/уклонение.
4. **Тряска камеры** при получении урона геройом (cameras.main.shake 120мс).
5. **Скриншоты сайта** переснять (таверна с портретом, бой, церковь).

### ФАЗА 2 — «Бой и ощущения»

### ФАЗА 4 — «Техдолг и полировка»
16. **EN-локализация диалогов** (thief.js ~35 строк, dialogue.js, интерьеры-описания).
17. **EN 404-страница** на сайте.
18. **Git LFS** для mp4 (трейлер) — иначе репо разбухает.
19. **DPR-чёткость**: game.config.resolution/zoom по devicePixelRatio, ретина-спрайты ×2 для HUD.
20. **SW-гигиена**: precache-лист v22 синхронизировать с факт-ассетами; для
    музыки/фонов — runtime-cache-only (уже так); добавить «Обновить игру»-кнопку
    при новом SW.
21. Оптимизация веса: главные PNG (tiles/lpc 15 МБ) — выборочно в WebP руками
    владельца в Godot (БЕЗ ffmpeg/CLI-конвертаций в песочнице).
22. 3D-модели GLB: препроцессинг в спрайт-листы средствами Godot у владельца
    (8 направлений × N кадров) — даст уникальных врагов (скелеты, волки-альфа,
    атаман) без стороннего арта. Песочница не рендерит 3D — только владелец.

### Правила (несокрушимые)
- НИКАКОГО ffmpeg в песочнице (OOM) — ассеты брать как есть.
- Пчёлы — только декор; погост и мельница — без монстров.
- Ассеты только из собственного репозитория владельца (DarklandsReborn/LPC) — лицензия чистая.
- Вес репо держать < 100 МБ: тяжёлое — лениво, precache — только критичное.
- Деплой = push в main; SW-версия +1 на каждый релиз с изменением ассетов.

- ФАЗА 3: реиграбельность (ярмарка/катакомбы/карта мира).
- ФАЗА 4: доступность (EN), производительность, вес.
