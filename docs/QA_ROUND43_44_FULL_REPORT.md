### 5. Возрастные ограничения и штрафы навыков/характеристик (данные — ролевая система) — ✅

- Модуль `systems/AgeRules.js`: таблица по **опциональному правилу старения BRP SRD** — базовой системе, на которой построена ролевая система **ChroniclesRuthenia** (docs/BRP_QUICKSTART_RU.md: «возраст и статус раздельно» по правилам BRP; старение — в списке опциональных правил SRD). - Порядок применения: характеристики → пересчёт производных BRP (HP=(КОН+РАЗМ)/10, бонус урона, MOV) → проценты навыков. Границы 3..99.

## 🔴 КРИТИЧЕСКИЙ СКРЫТЫЙ БАГ, НАЙДЕННЫЙ И ИСПРАВЛЕННЫЙ ДОПОЛНИТЕЛЬНО

**sw.js был синтаксически невалидным JavaScript с раунда 30:** в комментарии релиза v28 текст «деревья `deco_tree_*/deco_pine_*`» содержал последовательность `*/`, которая преждевременно ЗАКРЫВАЛА блочный комментарий `/* … */`. Весь остальной файл (включая `var CACHE_NAME`, обработчики, precache) оказывался вне комментария как мусорный код → Service Worker не компилировался и НЕ активировался. Следствие: офлайн-кэш и кэш-перезапись ассетов не работали с раунда 30 по 42 (игра продолжала работать только онлайн). Фикс: устранена последовательность `*/` внутри комментария (`deco_tree_N и deco_pine_N`); `node --check sw.js` — чисто; SW v42 активируется.
