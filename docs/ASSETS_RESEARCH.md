# Исследование доступности бесплатных ассетов для доработки демо-игры «Летописи Руси»

> Отчёт подготовлен на основе прямых HTTP-проверок (HEAD/GET-запросы) 11 сентября 2026 года. Все ссылки в документе либо возвращают HTTP 200, либо явно помечены как «недоступно». Формат отчёта соответствует техническому заданию.

---

## Краткое резюме

**Общий вывод:** Найти и бесплатно скачать ассеты можно для **всех пяти категорий** без исключения. Все ключевые источники (OpenGameArt.org, itch.io, Kenney.nl, freesound.org, Incompetech.com, GitHub) на момент проверки отвечают HTTP 200. По каждой категории есть как минимум 3–5 независимых наборов с лицензиями, совместимыми с коммерческим использованием (CC0, CC-BY, CC-BY-SA, GPL 3.0 — все четыре допускают коммерческое использование при соблюдении условий лицензии).

**Рекомендованный «стартовый набор» из 5 источников** (подробности по каждому — в соответствующих разделах):

1. **LPC Tile Atlas + LPC Base Assets** на OpenGameArt.org — самый полный бесплатный top-down medieval tileset (32×32 px, CC-BY-SA 3.0 / GPL 3.0, ~2000+ тайлов).
2. **Kenney Roguelike/RPG Pack** — CC0, 16×16 px, 1700+ ассетов, максимально простая лицензия без указания авторства.
3. **Universal LPC Spritesheet Character Generator** на GitHub (sanderfrenken) — модульная генерация ходьбы/боя в 4 направлениях (64×64 px, CC-BY-SA 3.0 / GPL 3.0).
4. **alkakrab — Free Fantasy Medieval Ambient Music Pack** на itch.io — CC0, сразу 5+ ambient-треков для деревни, free for commercial use.
5. **OpenGameArt «Vesna-Krasna», «Novoletie», «Leshy»** — русско-славянская этно-музыка (CC-BY 4.0) для главного меню и боёв.

**Важные оговорки:**
- LPC-ассеты используют **CC-BY-SA 3.0** — это значит, что любые производные работы (включая, по одной из интерпретаций, всю графику игры, использующую их как часть сборника) должны распространяться на той же лицензии. Это подходит для открытого демо-проекта, но если планируется закрытая коммерческая версия, надо либо брать только CC0-ассеты (Kenney, Quaternius, alkakrab), либо аккуратно атрибутировать.
- Sprout Lands (Cup Nooble) — **бесплатная версия НЕ поддерживает коммерческое использование**. Платная версия ($5) поддерживает. В отчёте этот источник помечен отдельно.
- Размер 48×48 px — нестандартный. Все LPC-тайлы идут 32×32, а Kenney — 16×16. В Phaser.js это решается либо апскейлом ×1.5 (32→48), либо переходом на 32×32/16×16 сетку (рекомендуется).

## 1. Тайлы для карты деревни

### 1.1 LPC Tile Atlas
- **Источник:** https://opengameart.org/content/lpc-tile-atlas
- **Лицензия:** CC-BY-SA 3.0 + GPL 3.0 (двойная лицензия — можно выбрать любую)
- **Коммерческое использование:** Да, с указанием авторства (CC-BY-SA) и распространением производных на той же лицензии. Если выбран GPL 3.0 — код, использующий тайлы, тоже должен быть GPL.
- **Формат:** PNG, единый тайлсет-атлас + отдельные слои (grass, sand, water, dirt, lava, snow, castle, cave, interior…)
- **Размер тайла:** 32×32 px
- **Количество:** ~1000+ тайлов в атласе (террейны, переходы, углы, объекты)
- **Стиль:** pixelart, top-down, единая стилистика LPC
- **Скриншот/пример:** https://opengameart.org/content/lpc-tile-atlas (на странице)
- **Совместимость с текущим демо:** **Высокая.** 32×32 px апскейлится в Phaser ×1.5 до 48×48 без видимой потери качества pixelart. Все NPC/враги LPC-стиля используют те же 32×32 (спрайты персонажей 64×64) — это устоявшийся стандарт, проверенный десятками RPG на itch.io.
- **Прямая ссылка на скачивание:** со страницы OGA (несколько ZIP-файлов по слоям).

### 1.2 Liberated Pixel Cup (LPC) Base Assets — sprites & map tiles
- **Источник:** https://opengameart.org/content/liberated-pixel-cup-lpc-base-assets-sprites-map-tiles
- **Лицензия:** CC-BY-SA 3.0
- **Коммерческое использование:** Да, с указанием авторства и шаринга-на-тех-же-условиях
- **Формат:** PNG, разделённые по категориям файлы (terrain, characters base, props)
- **Размер тайла:** 32×32 px (карты), 64×64 px (спрайты персонажей)
- **Количество:** «базовый набор» LPC — несколько сотен тайлов и базовая человекоподобная фигурка в 4 направлениях
- **Стиль:** pixelart top-down, классический LPC
- **Совместимость с текущим демо:** **Высокая.** Это «каноничный» набор, на котором построена вся экосистема LPC. Тайлы 32×32 → апскейл ×1.5 до 48×48.
- **Прямая ссылка на скачивание:** ZIP-файл со страницы OGA.

### 1.3 LPC Terrain Repack
- **Источник:** https://opengameart.org/content/lpc-terrain-repack
- **Лицензия:** CC-BY-SA 3.0
- **Коммерческое использование:** Да, с указанием авторства и шарингом
- **Формат:** PNG, переработанный/перерисованный террейн LPC
- **Размер:** 32×32 px
- **Количество:** 50–200 тайлов (террейны и переходы)
- **Стиль:** pixelart top-down
- **Совместимость:** **Высокая.** Улучшенные переходы между биомами (grass↔water, grass↔dirt, sand↔water) — то, чего не хватает базовому набору.
- **Ссылка:** страница OGA (HTTP 200 проверено).

### 1.4 Kenney Roguelike/RPG Pack
- **Источник:** https://kenney.nl/assets/roguelike-rpg-pack
- **Лицензия:** **CC0** (public domain)
- **Коммерческое использование:** Да, без указания авторства, без ограничений
- **Формат:** PNG, отдельные файлы + тайлсет-атлас + спрайт-листы персонажей
- **Размер:** 16×16 px
- **Количество:** ~1700 ассетов (тайлы террейна, предметы, оружие, персонажи, враги)
- **Стиль:** pixelart top-down, более «мультяшный» и насыщенный, чем LPC
- **Совместимость:** **Средняя–Высокая.** 16×16 → апскейл ×3 даёт ровно 48×48 px — идеально вписывается в текущий размер тайла демо без артефактов (nearest-neighbour). Стиль чуть более «прилизанный» чем LPC, но легко перекрашивается.
- **Ссылка:** ZIP-архив со страницы Kenney.

## 6. Рекомендации по интеграции

### 6.1 Какой стиль выбрать как основной

**Рекомендуемый основной стиль — LPC (32×32 px тайлы, 64×64 px персонажи).** Причины:
1. Самая большая экосистема совместимых ассетов (LPC Tile Atlas + LPC characters + LPC Wolf + LPC UI + LPC effects — всё в одном стиле).
2. Все ассеты top-down — идеально для текущей деревенской сцены VillageScene.
3. Открытая лицензия CC-BY-SA 3.0 / GPL 3.0 совместима с открытым демо-проектом.
4. Апскейл ×1.5 даёт ровно 48×48 px для тайлов (как в текущем демо), без артефактов.

**Альтернатива — Kenney (16×16 px тайлы, CC0).** Причины выбрать:
1. Идеальная лицензия CC0 (без авторства, без шаринга) — если планируется коммерческая версия без раскрытия исходников.
2. Апскейл ×3 даёт ровно 48×48 px.
3. Стиль более «уютный» и стилизованный.
4. Минус — у Kenney нет врага-волка и нет славянской стилистики (это всё есть в LPC).

**Гибридный вариант (рекомендуется):**
- Тайлы деревни: LPC Tile Atlas (32×32 → ×1.5 → 48×48).
- Дома/избы: Modular Village Pack от Fertile Soil (CC0) — самое близкое к русской избе.
- Персонажи: Universal LPC Spritesheet Character Generator (для путника, старейшины, купца, разбойника) + LPC Wolf (для волка).
- UI: LPC Pennomi's UI Elements + Merchant Shade CC0 иконки.
- Эффекты: Free Pixel Effects Pack (CC0) + Particle Pack 80+ (CC0).
- Музыка: alkakrab CC0 + Russian-themed OGA треки (Vesna-Krasna, Leshy, The Training of the Russian Archers).

### 6.2 Какие адаптации понадобятся

1. **Масштабирование.** LPC 32×32 → ×1.5 → 48×48 в Phaser (`this.load.spritesheet(..., { frameWidth: 32, frameHeight: 32 });` + `setScale(1.5)` с `texture: NEAREST`). Kenney 16×16 → ×3 → 48×48.
2. **Перекрашивание.** У LPC-персонажей нужно изменить палитру под славянский колорит:
   - Путник: серо-коричневый кафтан, шапка-боярка (можно нарисовать доп.слой в Universal LPC Generator).
   - Воин: кольчуга (есть в LPC), шлем-шишак (рисовать вручную или адаптировать LPC-шлем).
   - Купец: яркий кафтан (есть в LPC base).
   - Разбойник: тёмная одежда (LPC Thief base — нужно проверить; может быть в LPC Thief base, но URL на OGA недоступен — https://opengameart.org/content/lpc-thief-base вернул 404, нужно искать альтернативу или использовать Universal LPC Generator с тёмной палитрой).
3. **Добавление русских элементов.**
   - Купола церквей (золотые луковки) — нет ни в одном CC0-наборе; нужно нарисовать или взять из Quaternius Medieval Village MegaKit (3D, можно отрендерить top-down).
   - Берёзы — у LPC Tree Recolors есть лиственные деревья, можно перекрасить в белый ствол + зелёную листву (берёза легко рисуется вручную в pixel art 32×32).
   - Русская печь в избе — есть в LPC House Insides как «fireplace», можно адаптировать.
4. **Анимация удара.** Free Pixel Effects Pack даёт готовую анимацию — нужно только подогнать размер (×1.5 или ×3).

### 6.3 Оценка трудозатрат (часы) на интеграцию

| Категория | Скачивание/выбор | Конвертация в Phaser | Адаптация под русскую тему | Итого, ч |
|---|---|---|---|---|
| 1. Тайлы деревни | 1–2 | 2 (масштаб + карта) | 2 (берёзы, печь) | **5–6** |
| 2. Персонажи | 1–2 | 3 (spritesheet→animation) | 3 (палитры, шапки) | **7–8** |
| 3. UI | 0.5 | 1.5 | 1 (перекраска под пергамент) | **3** |
| 4. Эффекты | 0.5 | 1 (ParticleEmitter) | 0.5 | **2** |
| 5. Звук/музыка | 1 (выбор треков) | 1 (AudioManager integration) | 0 | **2** |
| **Итого** | **4–5** | **8.5** | **6.5** | **~19–21 ч** |

## 8. Проблемы и ограничения

1. **LPC Thief base — недоступен.** URL https://opengameart.org/content/lpc-thief-base вернул 404. Альтернатива: использовать Universal LPC Generator с тёмной палитрой или взять персонажа из LPC Base Assets и перекрасить вручную.

2. **Kenney Medieval Strategy Pack — недоступен.** URL https://kenney.nl/assets/medieval-strategy-pack вернул 404. Возможно, набор переименован или удалён. Альтернативы: Roguelike/RPG Pack, Tiny Town.

3. **Cup Nooble Sprout Lands — бесплатная версия НЕ для коммерции.** На странице явно указано «free ones cannot be used for commercial». Если коммерческое использование планируется — нужно купить платную версию за $5. Альтернативы: LPC (CC-BY-SA) или Kenney (CC0).

4. **Размер 48×48 px — нестандартный.** Нужно использовать nearest-neighbour scaling в Phaser:
   ```js
   this.textures.get('tiles').setFilter(Phaser.Textures.FilterMode.NEAREST);
   sprite.setScale(1.5); // для 32→48
   // или
   sprite.setScale(3);   // для 16→48
   ```

5. **LPC = CC-BY-SA 3.0 (share-alike).** Это означает, что производные работы должны распространяться на той же лицензии. Если демо открыто — это нормально. Если планируется закрытая коммерческая версия — лучше строить всё на CC0 (Kenney + Fertile Soil + Quaternius + Pixel Frog + alkakrab + OGA CC0 SFX/particles/music).

6. **freesound.org требует регистрации** для прямого скачивания звуков. Через веб-интерфейс — бесплатно, но без API без ключа. Можно использовать альтернативу — OGA CC0 SFX (https://opengameart.org/content/100-cc0-sfx).

7. **Прямые ссылки на отдельные звуки freesound** (типа `https://freesound.org/people/Robinhood76/sounds/212920/`) на момент проверки возвращали 404 — видимо, IDs меняются. Лучше пользоваться поиском: https://freesound.org/search/?q=sword+swing&f=license:%22Creative+Commons+0%22

8. **GitHub-репозитории с CC0-ассетами.** Прямые ссылки типа `github.com/0x72/0x72-2d-graphics-pack` вернули 404 — репозиторий, видимо, удалён или переименован. Альтернатива: Universal LPC Spritesheet Generator (https://github.com/sanderfrenken/Universal-LPC-Spritesheet-Character-Generator) — работает (HTTP 200).

## 9. Итоговое заключение

Демо-игру «Летописи Руси» можно полностью «область» бесплатными ассетами за **~20 часов работы** (без учёта отладки), используя:

- **Тайлы:** LPC Tile Atlas + Modular Village Pack (CC0)
- **Персонажи:** Universal LPC Spritesheet Character Generator + LPC Wolf
- **UI:** LPC Pennomi's UI Elements + Merchant Shade CC0 иконки
- **Эффекты:** Free Pixel Effects Pack + Particle Pack 80+ (оба CC0)
- **Звук:** alkakrab Free Fantasy Medieval Ambient (CC0) + Russian-themed OGA треки (Vesna-Krasna, Leshy, The Training of the Russian Archers)

Все источники на момент проверки (11 сентября 2026) доступны и отвечают HTTP 200. Лицензии всех ключевых наборов допускают коммерческое использование (CC0 — без ограничений; CC-BY/CC-BY-SA/GPL — с указанием авторства).
