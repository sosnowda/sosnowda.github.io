## 1. Суть проекта (для понимания исполнителя)

### 1.1. Что это за игра

**«Летописи Руси XV века» (Chronicles of Ruthenia)** — офлайн
AI-narrative RPG на движке **Godot 4.7.2**, действие которой разворачивается
на Руси **1400–1505 годов**: эпоха Василия I, Василия II «Тёмного» и
Ивана III «Великого» — «собирание земли русской», феодальные войны и
сбрасывание ордынского ига.

### 1.2. Уникальность (одной фразой)

**Математический движок BRP (d100, Basic Roleplaying SRD) считает броски,
урон, выживание, экономику и закон — а LLM-нарратор (локальная GGUF-модель
или облачный API) только художественно описывает готовый результат, опираясь
на жёсткую базу исторических фактов (RAG).**

### 1.3. Четыре столпа (продуктовые инварианты)

1. **Симбиоз математики и творчества** — все броски, урон, суды считает
   движок (правило **BRP-MATH**), ИИ только описывает.
2. **Жёсткий историзм (RAG-only)** — нарратор «не выдумывает, а выбирает
   и описывает» факты из 6+ RAG-баз (история, военное дело, персоны,
   общество, религия, география).
3. **Локальность и приватность** — игра и ИИ работают **офлайн**: модели
   скачиваются рантаймом с HuggingFace, ничего не уходит в облако без
   явного выбора игрока.
4. **Умное управление памятью** — Rolling Summary + State Injection вокруг
   малого контекстного окна (4–8k токенов): партия помнит квесты часовой
   давности без переполнения.

### 1.4. Ключевые факты (для страницы «Технические детали»)

| Параметр | Значение |
|---|---|
| Движок | Godot 4.7.2-stable (GDScript 2.0, рендер gl_compatibility) |
| Жанр | Текстовая повествовательная RPG / 2.5D-изометрия (на выбор) |
| Платформа | Windows Desktop (Linux — исходники) |
| Ролевая система | BRP Universal Game Engine SRD v1.01 (d100, Hit Locations, Damage Bonus) |
| ИИ-нарратор | Локальная GGUF (Saiga Llama 3 8B Q4_K_M, Saiga Gemma 3 12B, Vikhr-Nemo 12B) или облачный API (OpenAI/Mistral/DeepSeek/Jina/z.ai) |
| Эмбеддер RAG | mxbai-embed-large-v1 Q5_K_M (dim 1024, жёсткая фиксация) |
| RAG-базы | 6 JSON-баз (~32 МБ): история, военное дело, персоны, общество/религия, география, + динамическая «Память партии» |
| Время в игре | Юлианский календарь, старт 1 сентября 1400 г., ход реального времени |
| Города | 66 исторических городов 16 держав |
| Закон | Судебник 1497 (68 статей), Русская Правда, Псковская судная грамота |
| Объём кода | 358 .gd-файлов, 135 714 строк GDScript |
| Тесты | 1145 GUT-тестов (38 382 ассерта), 21 смоук-сцена, gdlint = 0 нарушений |
| Лицензия движка | MIT (Godot), BRP SRD — открытая лицензия |

### 1.5. Целевая аудитория сайта

- **Первичная:** игроки 25–45 лет, любители RPG с историческим сеттингом
  (Mount & Blade, Kingdom Come: Deliverance, Crusader Kings), интересующиеся
  русской историей и AI-технологиями.
- **Вторичная:** разработчики игр и AI-энтузиасты — которым интересна
  архитектура «LLM + детерминированное ядро», RAG-память, локальные модели.
- **Третичная:** историки-любители, реконструкторы, преподаватели истории
  средних веков.

### 1.6. Цель сайта

1. **Захватить внимание** первого посетителя за 5 секунд — уникальность
   проекта должна быть очевидна сразу.
2. **Объяснить механику** «математика + ИИ + RAG» простым языком, без
   технического жаргона в первом экране.
3. **Показать историческую достоверность** — эпоха, города, оружие, закон.
4. **Дать призыв к действию** — подписка на новости / скачать техдемо /
   посетить GitHub / поддержать разработку.

## 2. Уникальное торговое предложение (УТП)

### 2.1. Главная формула

> **«ИИ-нарратор + детерминированная BRP-математика + жёсткий RAG по
> истории Руси XV века = бесконечная, исторически достоверная
> ролевая партия, в которой невозможно "зарегистрироваться королём".»**

### 2.2. Три ключевых дифференциатора

| # | Дифференциатор | Расшифровка |
|---|---|---|
| 1 | **ИИ описывает, но не решает** | Все исходы считает движок BRP (d100) — ИИ не может «смиловать» игрока или выдать счастливую концовку. Бой один удачный удар может убить. Удача зависит от бросков, а не от настроения нейросети. |
| 2 | **Жёсткий историзм** | РAG из 6 баз по ~32 МБ исторических фактов: события 1400–1505 (Грюнвальд, падение Константинополя, стояние на Угре), оружие и доспехи эпохи, персоны, география 66 городов, Судебник 1497. Нарратор не выдумывает пушки в 1420 году. |
| 3 | **Полная локальность** | Игра работает офлайн. Модель Saiga Llama 3 8B (4.6 ГБ) запускается на домашнем CPU/GPU через llama.cpp. Никаких подписок, никаких облаков — если игрок не выбрал внешний API сам. |

### 2.3. Что НЕ делать (категорически)

- ❌ Не описывать как «AI-игру, где ИИ всё решает» — это ложь, ИИ только
  описывает.
- ❌ Не обещать «открытый мир» — игра повествовательная, с текстовым
  интерфейсом (опционально 2.5D-изометрия для боя).
- ❌ Не называть «MMO» или «онлайн» — игра офлайн, сетевой активности нет
  (только опциональные HTTP-запросы к облаку провайдера API).
- ❌ Не сравнивать с ChatGPT — это не чат-бот, это RPG с детерминированной
  механикой.
- ❌ Не использовать кликбейт: «ИИ заменит гейм-мастера» и т.п.

### 3.2. Что это за игра? (1 экран, ~400 слов)

Три блока с иконками:

1. **«Симбиоз математики и творчества»** — Godot считает броски d100,
   урон, локации попадания, тяжёлые раны, выкуп по Судебнику 1497. ИИ
   только описывает готовый результат.
2. **«Жёсткий историзм»** — многобазовый RAG по истории Руси: события
   (Грюнвальд 1410, падение Константинополя 1453, стояние на Угре 1480),
   оружие и доспехи (меч, сабля, бердыш, кольчуга, зерцало), персоны
   (Иван III, Марфа Борецкая, София Палеолог), 66 городов 16 держав.
3. **«Локальность и приватность»** — игра работает офлайн. Модель 4.6 ГБ
   скачивается один раз, потом — никаких облаков.

### 3.3. Как это работает (1 экран, схема + 3 шага)

**Схема потока:**
```
Игрок вводит действие
        ↓
NarrativeController.detect_action_type
        ↓
┌─────────────┬─────────────┬─────────────┐
│   БОЙ       │  НАВЫК      │  ДИАЛОГ     │
│ (BRP d100)  │ (BRP d100)  │             │
└──────┬──────┴──────┬──────┴──────┬──────┘
       ↓             ↓             ↓
Математический исход (детерминированный)
       ↓             ↓             ↓
       └───────┬─────┴─────────────┘
               ↓
   PromptBuilder + RAG (косинусный поиск по 6 базам)
               ↓
   LLM-нарратор (локальная Saiga или облачный API)
               ↓
   Художественное описание на русском языке
               ↓
   Запись в «Летопись партии» + RAG-память
```

**Три шага для пользователя (проще):**
1. **Вводишь действие текстом** — «Атакую разбойника мечом в голову»,
   «Уговариваю воеводу дать лошадей», «Крадусь к лагерю ночью».
2. **Движок считает исход** — бросок d100 против навыка, степень успеха
   (крит / особый / успех / провал / фамбл), локация попадания, урон,
   тяжёлая рана с потерей характеристик, нокаут «взять живым».
3. **Нарратор описывает** — LLM получает готовый итог + релевантные
   факты из RAG (как выглядел меч, как звали воеводу, что говорит
   Судебник), и пишет художественный текст на русском.

### 3.5. Ролевая система BRP (1 экран, для гиков)

**Basic Roleplaying Universal Game Engine SRD v1.01** — открытая
система (Chaosium, открытая лицензия). Используется в Call of Cthulhu,
RuneQuest, Stormbringer.

**Ключевые механики (с маленькими иконками):**
- 🎲 **d100** — проверка навыка против шанса (5–99%).
- ⭐ **Степени успеха** — критический (1/20), особый (1/5), успех, провал,
  фамбл (≥95+крит).
- 🎯 **Hit Locations** — d20-таблица: прав. нога 1–4, лев. нога 5–8,
  живот 9–11, грудь 12, руки, голова.
- 🩸 **Тяжёлая рана** — урон ≥ половины HP → таблица d100 с потерей
  характеристик (DEX/STR/CON/CHA/INT) по зонам.
- 🛡️ **Броня AP** — по локациям: кольчуга 4, зерцало 6.
- ⚔️ **Урон** — Damage Bonus по СИЛ+РАЗМ: от −1D6 до +4D6 и выше.
- 🤝 **Встречный бросок** — особый против особого → оба деградируют до
  провала (SRD p. 112).
- 🤛 **Нокаут «взять живым»** — тупое оружие, удар в голову, субдуальный
  урон (HP не ниже 1), проверка CON×5.
- 💰 **Выкуп по Судебнику 1497** — пленный = деньги в кампанию.

### 3.6. ИИ-стек (1 экран, для технарей)

**Три режима работы нарратора:**

| Режим | Что нужно | Скорость | Приватность |
|---|---|---|---|
| **Локальный** (по умолчанию) | llama.cpp + GGUF 4.6 ГБ | средняя | полная |
| **Облачный API** | ключ OpenAI/Mistral/DeepSeek | высокая | данные уходят к провайдеру |
| **Офлайн-заглушка** | ничего | мгновенно | полная, но текст шаблонный |

**Модели в каталоге:**
- 🥇 **Saiga Llama 3 8B Q4_K_M** (4.6 ГБ) — рекомендуемая, баланс.
- **Saiga Gemma 3 12B Q4** (6.8 ГБ) — для GPU 10+ ГБ.
- **Vikhr-Nemo 12B** (6.8 ГБ) — строгие факты + живая речь.

**Эмбеддер RAG:** mxbai-embed-large-v1 Q5_K_M (235 МБ, dim 1024).
Жёсткая фиксация — другой квант = другое векторное пространство,
переиндексация всех баз.

**RAG-базы (6 JSON, ~32 МБ):**
1. `history` — события 1400–1505.
2. `military` — оружие, доспехи, тактика.
3. `persons` — исторические персоны.
4. `society` — общество, культура, религия.
5. `geography` — 66 городов, пути, расстояния.
6. `game_memory` — динамическая, «помнит» партию.

  модулем и экономикой.

### 3.10. FAQ (1 экран, аккордеон)

**Q: Нужен ли интернет для игры?**
A: Нет. Локальная модель Saiga Llama 3 8B (4.6 ГБ) работает офлайн через
llama.cpp. Облачный API — опция для тех, кто хочет быстрее.

**Q: Какое железо нужно?**
A: Минимум — 8 ГБ ОЗУ, любой CPU постарше. Рекомендуется — 16 ГБ ОЗУ +
GPU 6+ ГБ. Модель Q4_K_M на CPU даёт ~2-4 токена/сек, на GPU 6 ГБ —
~15-20.

**Q: Игра на русском?**
A: Да, полностью. Все тексты, интерфейс, RAG-базы, нарратор — на русском.
Модели Saiga / Vikhr — русскоязычные.

**Q: Это бесплатно?**
A: Код открыт (MIT). Модели — открытые (HuggingFace). Готовая игра будет
  платной в Steam, но техдемо — бесплатно.

**Q: Можно ли играть без ИИ?**
A: Технически да — есть офлайн-заглушка с шаблонными текстами. Но это
  теряет 90% сути проекта.

**Q: Когда релиз?**
A: Точной даты нет. Подпишитесь на новости (форма в подвале) — узнаете
  первым.

**Q: Как поддержать разработку?**
A: Звезда на GitHub, репост, подписка. Краудфандинг — в планах.

**Q: Можно ли контрибьютить?**
A: Да! issues и PR приветствуются. Читайте `AGENTS.md` в репозитории —
  там правила для ИИ-агентов и людей.

### 6.1. Стек (на выбор исполнителя)

**Вариант A — статика (рекомендуется):**

**Вариант C — Tilda / Webflow:**
- Для не-разработчиков. Ограничения по кастомизации, но быстро.

**Рекомендация:** Вариант A — статика. Быстрее, дешевле, доступнее
