# Раунд 58 — СИМУЛЯЦИЯ ПОГОНИ И АНАЛИЗ БАЛАНСА (п.3 приказа владельца)

Дата: 19.09.2026 · Инструмент: `game/tools/chase-sim.mjs` (новый, N=1200 сеансов на строку отчёта)

## Что считалось

Полные сеансы охоты на вора НАСТОЯЩЕЙ логикой игры (`data/thief.js`: маршруты
из 3 остановок, следы 12–24 ч, наводки свидетелей 5 ч, заморозки 2 ч, побег из
боя 3 ч) + боем по правилам CombatScene (BRP d100, 1:1 с `tools/battle-sim.mjs`,
с переносом HP вора между боями — п.11) + экономикой времени раунда 58
(разговор 10 мин, вход в дом 10 мин, обследование следа 1 ч, дорога 1–2 ч).

Стратегии игрока:
- **Слепой поиск** — случайные локации, без расспросов;
- **Следопыт** — систематический обход локаций + чтение следов;
- **Расспрос селян** — опрос свидетелей (3–5 из 30 взрослых), наводки, погоня по наводкам.

## БАЗА: сколько времени у игрока

Вор без всяких действий игрока уходит в среднем за **22,7 ч** (минимум 9 ч,
максимум 35 ч) — это окно погони.

## ВЫВОДЫ ДЛЯ ВЛАДЕЛЬЦА

### 1. Насколько легко пройти / проиграть
- **Осмысленная игра (расспросы + наводки) почти всегда приводит к победе:
  85–99 %** — игра честная, «пройти» реально каждым из 8 героев.
- **Проиграть реально двумя путями**: (а) игнорировать расспросы — слепой
  поиск ловит вора лишь в 35–66 % случаев; (б) лезть в бой слабым бойцом —
  рэйнджеры (лук, мало HP) гибнут в 10–15 % боёв с вором. Оба риска
  телеграфированы игроку (свидетели говорят прямо, здоровье видно в HUD).
- Смертность воинов/следопытов в бою ~0–3 % — вор опасен именно для
  «немasteryх в драке», что соответствует его задумке (ловкий, но не боец).

### 2. Влияние раунда 58 п.1 (разговор 1 ч → 10 мин)
- Победные стратегии почти не изменились по шансам (воин 98,5 → 99 %),
  но **стоимость умной игры упала вдвое-втрое**: полный опрос свидетелей
  теперь ~2,3 ч вместо 5,7 ч; авантюристы перестали массово упускать вора
  (бегства 11–13 % → 1,6–2,3 %).
- Слепые стратегии не изменились (их цена — дорога и осмотр, не разговоры).
- Вывод: правка раунда 58 сделала игру **добрее к любопытным игрокам**
  (больше разговоров за то же время), не сломав баланс.

### 3. Что лучше балансировать (рекомендации)
- **Сложность боя — НЕ трогать**: вор (атака 50 %, кинжал 1d6+1, броня 2)
  даёт уместный риск слабым героям и быстро проигрывает тяжёлым классам.
  Это правильная асимметрия «класс ⇒ тактика».
- **Время убегания/остановок — НЕ трогать**: окно 9–35 ч (среднее 22,7 ч)
  при умной игре используется на 20–30 %; для слепой игры оно и так дефицитно.
  Удлинять — убьёт напряжение; укорачивать — сделает слепую игру безнадёжной.
- **Единственная найденная неувязка: стратегия «Следопыт» хуже слепого
  поиска** (18–40 % против 35–66 %). Систематический обход вознаграждается
  хуже случайного, потому что: (а) осмотр локации без следа сгорает навсегда,
  (б) след читается проверкой Внимательности (провал = локация потрачена),
  (в) порядок обхода не учитывает дальность (лесные локации далеко). Это не
  срочно: «следопыт» — самоограниченная стратегия, но если захочется
  усилить — дать при провале проверки Внимательности «частичную» информацию
  (сторону света) или не сжигать локацию при провале.

### 4. Прогон полного сеанса в браузере (стенд)
Создание героя (Гаврила, следопыт) → деревня → разговор (ровно +10 мин) →
вход в дом (ровно +10 мин) → выход за ворота (1 ч) → Тракт на юг → встреча
с вором на arrival → бой (Лук) → «Вор повержен!» → возврат иконы священнику
(награда 28 д. + благословение) → финал «🏆 ПОБЕДА! ИКОНА ВОЗВРАЩЕНА»,
оценка 3★ «Старательный путник», хроника действий целая. Консоль — 0 ошибок.
