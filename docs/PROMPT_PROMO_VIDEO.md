## 1. Суть проекта (для понимания исполнителя)

### 1.1. Что это за игра

**«Летописи Руси XV века» (Chronicles of Ruthenia)** — офлайн
AI-narrative RPG на движке **Godot 4.7.2**, действие которой разворачивается
на Руси **1400–1505 годов**: эпоха Василия I, Василия II «Тёмного» и
Ивана III «Великого» — «собирание земли русской», феодальные войны и
сбрасывание ордынского ига.

### 1.2. Уникальность (одной фразой)

**Математический движок BRP (d100, Basic Roleplaying SRD) считает броски,
урон, выживание, экономику и закон — а LLM-нарратор (локальная GGUF-модель
или облачный API) только художественно описывает готовый результат, опираясь
на жёсткую базу исторических фактов (RAG).**

### 1.3. Четыре столпа

1. **Симбиоз математики и творчества** — все броски, урон, суды считает
   движок (правило **BRP-MATH**), ИИ только описывает.
2. **Жёсткий историзм (RAG-only)** — нарратор «не выдумывает, а выбирает
   и описывает» факты из 6 RAG-баз.
3. **Локальность и приватность** — игра и ИИ работают офлайн.
4. **Умное управление памятью** — Rolling Summary + State Injection.

### 1.4. Ключевые факты для ролика

| Параметр | Значение |
|---|---|
| Движок | Godot 4.7.2 |
| Жанр | Текстовая повествовательная RPG / 2.5D-изометрия |
| Ролевая система | BRP SRD d100 (Hit Locations, Damage Bonus) |
| ИИ-нарратор | Saiga Llama 3 8B (локально, офлайн) или облачный API |
| RAG | 6 баз (~32 МБ) по истории Руси |
| Время в игре | 1400–1505, Юлианский календарь |
| Города | 66 исторических городов 16 держав |
| Закон | Судебник 1497 (68 статей) |
| Бой | Один удачный удар может убить; нокаут «взять живым»; выкуп |
| Тесты | 1145 GUT, 21 смоук, gdlint = 0 |

### 1.5. Целевая аудитория ролика

- **Первичная:** геймеры 25–45 лет, любители RPG с историческим сеттингом
  (Mount & Blade, Kingdom Come, Crusader Kings).
- **Вторичная:** AI-энтузиасты, разработчики игр.
- **Третичная:** историки-любители, реконструкторы.

### 1.6. Цель ролика

1. **За первые 3 секунды** захватить внимание уникальностью:
   «AI-narrative RPG по Руси XV века».
2. **За 30 секунд** объяснить механику: ИИ описывает, математика решает.
3. **За 60–90 секунд** показать историческую глубину и вызвать желание
   «скачать / подписаться».

## 2. Уникальное торговое предложение (УТП)

### 2.1. Главная формула

> **«ИИ-нарратор + детерминированная BRP-математика + жёсткий RAG по
> истории Руси XV века = бесконечная, исторически достоверная
> ролевая партия.»**

### 2.2. Три дифференциатора (для озвучивания в ролике)

1. **«ИИ описывает, но не решает»** — все исходы считает движок BRP (d100),
   ИИ не может «смиловать» игрока. Один удачный удар может убить.
2. **«Жёсткий историзм»** — RAG по 6 базам: события, оружие, персоны,
   города, закон. Нарратор не выдумывает пушки в 1420 году.
3. **«Полная локальность»** — модель Saiga 4.6 ГБ работает офлайн через
   llama.cpp. Никаких облаков.

### 2.3. Что НЕ показывать (категорически)

- ❌ Не показывать как «AI всё решает за тебя» — ИИ только описывает.
- ❌ Не обещать «открытый мир» — игра повествовательная.
- ❌ Не использовать кадры из других игр (Skyrim, Witcher) — даже как
  референсы для AI.
- ❌ Не называть «MMO» или «онлайн».
- ❌ Не показывать современные элементы (пушки в 1400 году, христианские
  кресты на щитах до Куликова и т.п.) — историзм обязателен.

## 3. Формат ролика

### 3.1. Хронометраж

**Основной ролик: 90 секунд** (для YouTube / Rutube / VK Видео).

**Дополнительные версии:**
- **Тизер 15 секунд** (для Shorts / Reels / TikTok / VK Клипов).
- **Расширенный 2:30** (для GitHub README / landing page).

### 3.2. Соотношение сторон

- **16:9** (1920×1080) — основная версия.
- **9:16** (1080×1920) — вертикальная для Shorts / Reels.
- **1:1** (1080×1080) — квадратная для VK / Telegram premium.

### 3.3. FPS и кодек

- **30 fps** (для плавности) или **24 fps** (для кинематографичности).
- **H.264** (mp4) — для совместимости.
- **Bitrate:** 8–12 Mbps для 1080p.

### 3.4. Язык

- **Русский** — основной (диктор + титры).
- **Английские субтитры** — опционально (для международной аудитории).

- **Основной текст:** PT Sans.

### 5.3. Стиль визуального ряда (на выбор)

**Вариант A — Стилизованный пиксель-арт** (как Disco Elysium):
- Изометрия, тёмная палитра, акцент на тексте.
- Анимация — покадровая, 12 fps для персонажей, 30 fps для камеры.
- Плюс: дёшево, стильно, узнаваемо.
- Минус: нужно рисовать много кадров.

**Вариант B — Чистый 3D с фольгированной текстурой** (как Pathologic 2):
- 3D-модели + пост-обработка под живопись.
- Плюс: реалистично.
- Минус: дорого.

**Вариант C — Гибрид: 3D + пиксельные элементы UI** (как Return of the
Obra Dinn):
- 3D-сцены + 2D-текст и иконки.
- Плюс: стильно, дёшево.
- Минус: сложно сбалансировать.

**Вариант D — AI-генерация** (Sora / Runway / Kling):
- Промпты для каждой сцены (см. раздел 8).
- Плюс: быстро, дёшево.
- Минус: нужен монтаж, может быть «мыло».

**Рекомендация:** Вариант A или D — в зависимости от бюджета.
