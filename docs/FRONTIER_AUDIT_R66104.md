## 8. DISTILL (правила гейта — кандидаты в стандарт; сохранены дословно по смыслу)

1. **writing/landing**: секция CTA без кликабельного элемента хуже отсутствия CTA — каждый
   риторический подъём обязан заканчиваться действием. Тест: посчитать `<a>/<button>`
   внутри секции.
2. **design/first-screen**: первый экран обязан называть категорию и ценность видимым
   текстом; hero, проходящий kill test по арту, всё равно проваливает 3-секундный тест,
   если весь видимый текст — картинка. sr-only h1 и `<title>` не считаются.
3. **translation**: обещание интеракции в копирайте локали должно иметь соответствующий
   элемент в той же локали; расхождение интро между локалями = coherence drift. Кандидат
   в автотест: «imperative → element exists».
4. **historicism**: привязка события к году проверяется на то, что событие произошло
   именно в этом году; одна конкалендарная ошибка откатывает весь USP. Хроника лендинга
   обязана проходить через тот же контроль, что и игра.
5. **brand/restraint**: emoji-иконки ломают заявленный «авторский/музейный» регистр; если
   hero-арт авторский, иконки — из той же руки. Всё, что удаляется без потери смысла,
   удаляется.
6. **marketing**: монетизация не бывает sticky на нулевом пикселе недоказанного
   альфа-продукта; ask ставится после proof.
7. **code hygiene**: внутренние дневники аудита (номера раундов, «приказ владельца»)
   срезаются из прод-HTML на этапе сборки — процессная лексика в shipped-коде —
   любительский tell.
8. **meta/rubric gaming**: там, где есть метрика (Lighthouse), качество концентрируется;
   где нет (интеграционность контента) — рассыпается. В каждый gate добавлять один
   интеграционный чек, не покрытый метриками.
9. **Золотой пример (writing/storytelling)**: внутриигровая проза — «молоко — вот это
   молоко: ложка стоит, столбом!» (dialogue.js:2523), «Утром Прасковья пирогами ветер
   гоняет» (:2803) — голосная народная речь как регистр-стандарт; лендингу равняться на
   него вместо шаблонных feature-card.
