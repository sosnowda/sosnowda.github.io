## Технические детали

- **Конверсия спрайтов:** 8×4 кадра @128 px → 4×4 @64 px (ряды: вниз/влево/вправо/вверх — совпадают с игровым форматом; `BootScene.createWalkAnimations` создаёт walk/idle-анимации для всех 6 новых листов).
- **Пайплайн:** `tiles_dl/convert_assets.py` (PIL): bbox-обрезка тайловых блоков, резка/тонировка рендеров, сборка интерьеров; `fbx_render/render.js` (three.js + playwright-core) — рендер FBX с прозрачным фоном.
- **Интерьеры в коде:** `InteriorScene.addDecorations` — если есть `int_bg_<id>`, фон рисуется растянутым на экран (depth −6), процедурные пол/стены/окна и статический декор пропускаются; живыми остаются анимированный огонь, киот и свет. Ночь при фоне мягче: `min(alpha×0.55, 0.38)` + тёплые пятна света над запечёнными очагами.
- **QA в браузере (agent-browser):** полный поток «титул → преген → облик → деревня → дом ткачихи (ткацкий стан на месте) → выход → развилка → карта местности (фикс Густого леса) → Лес → встреча с воровкой (текст+спрайт) → клик нижней кнопки при открытом диалоге (п.1 работает) → бой с воровкой (её спрайт в бою)»; генератор: имя/класс/возраст/облик, фильтр пола; ночь в доме Марфы после 2 фиксов (гвард подложки −5 поверх фона −6; `_lightSources` до инициализации). Итог: page errors пусты.
- **Найдено и исправлено в ходе QA:** 1) `ReferenceError: height` в новой сцене облика; 2) чёрный интерьер — подложка пола (depth −5) перекрывала фон (depth −6); 3) пуш в `_lightSources` до её создания; 4) `step`→`step2` в `refreshHeroes`.
