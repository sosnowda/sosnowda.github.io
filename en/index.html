About the project

Where mathematics meets storytelling

The Chronicles of Ruthenia is a project in which the Godot game engine (desktop version) handles all the math: dice rolls, damage calculation, hit chances, skill and survival checks. Meanwhile an AI Narrator (a local llama model or a cloud LLM) runs the game as its Game Master: describing the world, the dialogue and the consequences of your actions. The browser demo on this page is built with Phaser 3.

But most importantly — strict historical authenticity. A RAG knowledge base compiled from historical books and articles keeps the neural network from hallucinating and inventing facts. Everything that happens in the game is checked for historical accuracy.

RAG Historical Knowledge Base

A multi-source Retrieval-Augmented Generation system filled with real historical sources on 15th-century Rus' and world history. Every claim the Narrator makes is checked against verified facts.

BRP Universal Game Engine d100

The mathematically rigorous Basic Roleplaying system, carefully adapted to the 15th-century Rus' setting, with realistic odds, skills and combat mechanics.

LLM Narrator

A local neural network on llama.cpp server, or any cloud model via an OpenAI-compatible API. Narrative quality depends on the chosen model and its weights.

Realistic Turn-Based Combat

Graphical combat in 2.5D isometric view or a text mode. Historically accurate weapons, armour and clothing. You can die from a single well-placed blow to a vulnerable spot.

A Living Historical World

Every world event is reflected in the game: rumours from merchants, news from foreign guests, political shifts. Day and night, seasons and weather change. Realistic roads and distances.

Smart Memory Management

Rolling Summary + State Injection around the model's context window. No context overflow — the AI always remembers the key events of your story.

Technical foundation

How it works

Project architecture

  • Godot game engine — manages the game environment, loads neural networks, performs all calculations and supervises the historical accuracy of prompts via the RAG base.
  • Local neural network — downloaded from a Hugging Face repository on first launch. Works offline through llama.cpp server.
  • Cloud models — connect any model with your OpenAI-compatible API key by specifying the provider address and model name.
  • RAG knowledge base — compiled from historical books and articles. Verifies every prompt for historical accuracy before it reaches the neural network.
  • BRP d100 — the Chaosium BRP Universal Game Engine SRD roleplaying system. All rolls, damage, skills and checks are computed by the engine.
  • Built-in embedding model — mxbai-embed-large-v1 · Q5_K_M · dim 1024 · cosine search. A second neural network for the RAG knowledge base.
  • Rolling Summary + State Injection — intelligent context-window management that prevents overflow while preserving key events.
  • Full list of neural network models:
    • Local: Saiga Llama 3 8B (Q2_K/Q4_K_M/Q8_0), Saiga Gemma 3 12B (Q3_K_M/Q4_K_M/Q6), Vikhr-Nemo 12B (Q4_K_M/Q5_K_M/Q6), Vikhr-YandexGPT 5 Lite 8B (Q4_K_M), Gemma-4 E4B-Uncensored (Q4_K_M)
    • Cloud: Any cloud neural network can be connected using an OpenAI-compatible API key.
    • Embedder (knowledge base): mxbai-embed-large-v1 · Q5_K_M · dim 1024 · cosine search
