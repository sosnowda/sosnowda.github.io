# LPC Style Farm Animals — credits

Source: https://opengameart.org/content/lpc-style-farm-animals
Authors: multiple LPC contributors
License: CC-BY 3.0 / GPL 3.0 (dual)

Animals:
- cow (8×8 walk, 8×8 eat)
- llama (8×8 walk, 8×8 eat) 
- pig (8×8 walk, 8×8 eat)
- sheep (8×8 walk, 8×8 eat)
- chicken (2×2 walk, 2×2 eat)

Walk sheets: 4 dirs × 7 frames (cols 1-6 walk, col 7 idle).
Directions: row 0 = down, row 1 = left, row 2 = right, row 3 = up.

Frame size: 64×64 px.
