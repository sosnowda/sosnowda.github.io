# Fantasy Knight — credits

Source: https://aamatniekss.itch.io/fantasy-knight-free-pixelart-animated-character
Author: aamatniekss
License: Free for personal and commercial use (attribution appreciated)

Files are 120×80 px per frame, single row (facing right).
Use `load.spritesheet('knight_idle', 'sprites/knight/idle.png', { frameWidth: 120, frameHeight: 80 })`.

Animation list:
- idle (10 frames) — breathing/idle
- walk (10 frames) — running (use for walking)
- attack1 (4 frames) — basic sword swing
- attack2 (6 frames) — alternate swing
- attack_cmb (10 frames) — combo swing
- hit (1 frame) — getting hit
- death (10 frames) — falling and dying
- jump / fall / roll / slide / dash / crouch — extra animations

Color variants: <anim>.png (Colour1), <anim>_c2.png (Colour2).
