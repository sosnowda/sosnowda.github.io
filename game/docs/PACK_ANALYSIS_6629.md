# Анализ пака «Medieval - Heroes I» (Drive владельца) — 66.29

Источник: https://drive.google.com/drive/folders/1p_tJFXiaQPEO1-EQVqg6dwnvvSyg2e3s
Дата анализа: 66.29 (сентябрь 2026). Скачано выборочно — Drive лимитирует массовую
выгрузку (gdown падает по 500-м на подпапках), полный пак — десятки тысяч файлов.

## Структура пака (по факту выгрузки)

```
Medieval - Heroes I/
  Baenor/        67 файлов  — ПОЛНЫЙ (default, MVsv, Bust_1..8, Face, Mastersheet, действия+diag)
  Huntress/      33         — default ✓, Bust_1..8 ✓, Mastersheet нет
  MasterGaerron/ 51         — default ✓, MVsv ✓, Mastersheet ✓, бастов нет
  Naia/          17         — MVsv есть, default/Mastersheet не докачались
  PaulHammerArm/ 15         — Mastersheet есть, default нет
  LordEsther/    45         — Mastersheet есть
  Leyanne/        8         — начата
  Saurial/       11         — MVsv есть
Medieval - Interiors/        —Humans/Children/... (интерьерные люди, десятки тысяч слоёв)
```

Ключевые листы на героя:
- `{Hero}_default.png` 384×512 = 4×4 кадров 96×128 — walk-цикл вниз/влево/вправо/вверх
  (тот же порядок, что в игровых hero_*.png 4×4@64).
- `{Hero}_MVsv.png` 1152×768 = 12×8 кадров 96×96 — боевые анимации (удары мечом
  по направлениям, смерть/лежание) — кандидат на замену «knight» в CombatScene.
- `{Hero}_Bust_1..8.png` 512×512 — портреты-эмоции (экран выбора/диалоги).
- `{Hero}_Mastersheet.png` 3072×3072 = 32×32 кадров 96×96 — ВСЁ, но кадры ОБРЕЗАНЫ
  по ступни (контент упирается в нижний край кадра) — walk из мастера не извлечь.

## Что сделано в 66.29

- hero_baenor.png и hero_huntress.png заменены walk-листами пака: конвейер
  (скрипт вне репо scripts/convert_hero_walks.py) ресайзит кадры 96×128 → 48×64
  и кладёт на канву 64×64 с ногами на y=60 и центром x=32 — полная совместимость
  с createWalkAnimations и всей логикой размещения (замер контента совпал с
  прежними листами: ноги y≈60, ширина ~48).
- Конвейер проверен на MasterGaerron (hero_gaerron.png готов вне репо).

## Что осталось на следующую итерацию (66.30)

1. Докачать папки Naia/PaulHammerArm (нужны default.png), Leyanne, LordEsther,
   Saurial — просить владельца переложить их в отдельную папку или выдать
   прямые ссылки (gdown по файлу работает стабильно).
2. MVsv → CombatScene: заменить «fantasy knight» боевыми листами героев
   (нужна карта строк MVsv: удары по 4 направлениям × 3 удара, смерть —
   снимается визуально за один прогон по Баэнору).
3. Bust_1..8 → CharacterSelectionScene/диалоги (портреты эмоций вместо
   walk-кадра-иконки).
4. Medieval_Interiors/Humans — интерьерные фигуры (96×128) как альтернатива
   LPC-композитам НПЦ в интерьерах (сравнить стиль с запечёнными фонами —
   он совпадает: это тот же автор, что и фоны int_bg).
5. ЛИЦЕНЗИИ: у пака нет LICENSE-файла в выгрузке — перед использованием
   новых ассетов (MVsv/басты) запросить у владельца условия распространения
   (пак куплен/получен владельцем; hero_* уже в игре с раунда 50 —
   прецедент использования есть).
