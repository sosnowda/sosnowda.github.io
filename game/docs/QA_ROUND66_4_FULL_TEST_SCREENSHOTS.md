2. **Alt-текст скриншота 9**: «на погосте» → «на берегу реки» (сцена — Location river).
3. **ScreenshotDirector**: `custom` теперь снимает лист Гаврилы (`selectHero(PRESET_HEROES[0])`) — совпадает с alt на сайте; добавлен сценарий `blacksmith` (10-й кадр).

## 4. Ограничения среды (не баги игры)

Headless-браузер песочницы после нескольких навигаций деградирует:
- не растеризует крупные fullscreen-заливки (overlay ночи/погодой — «ложная не-ночь»; проверено: тот же билд в свежей сессии рисует ночь корректно, свойства overlay при «отказе» корректны: fillColor 0x191938, fillAlpha 0.55, depth 90, scrollFactor 0);
- подвешивает delayedCall-таймеры сцены (подсказка туториала «Беженец» не исчезает; updateHUD при этом живёт через scene.update);
- `[shots] boot timeout` при cold-загрузке.
Каждый симптом перепроверен в свежей сессии — воспроизводится только в деградировавшей headless-сессии. Код игры здоров; скриншоты сняты из здоровых сессий (по одному кадру на запуск браузера).
