## Секция A — п.11-в: лестница статусов + лёгкий осмотр у ворот

- Репутация −25 → статус-бар: **«⭐Деревня: −25 (подозрительный)»** (qa80_a1).
- Выход через ворота с краденым в узле: стражник останавливает, поп-ап
  **«🛡 Осмотр у ворот»** со списком чужого добра (qa80_a2).
- Краденое изъято, честное имущество не тронуто, **денег не взяли** (100 → 100),

  репутация −10 (выше −20) — осмотра нет; полная поимка (п.5 66.79) не задета.

## Секция B — п.11-г: епитимья «Замолить грехи» в церкви

- Кнопка **«⛪ Замолить грехи (50 д.)»** видна только при молве < 0 и если
  в этом месяце епитимья ещё не принималась (священник утром в церкви).
- Клик: поп-ап «⛪ Грехи замолены» (qa80_b2), списание 50 д. (100 → 50),
  репутация **−7 → −2** (+5 к нулю), ключ месяца `absolutionMonthKey` записан.
- Повторно в тот же месяц кнопки НЕТ (использованный месяц скрыт из UI).
- Отрицательный контроль (юнит-тесты): при репутации ≥ 0 — «замаливать
  нечего»; −2 → 0 ровно (выше нуля не тянет); новый месяц — снова можно.
