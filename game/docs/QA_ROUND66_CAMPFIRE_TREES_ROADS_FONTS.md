## Ключевые решения
- **Отдых без лечения** смещает ценность к постоялому двору (4 д.) и молебну — костёр стал тактическим «переждать ночь/до срока». Это ровно формулировка владельца «МОЖЕТ ТОЛЬКО ПРОМОТАТЬ ВРЕМЯ».
- **Один западный проезд** вместо двух боковых: восточный упирался в дом знахарки (кол. 23–24) — геометрия подсказала минимум дорог; сеть остаётся единой (BFS).
- **Валидатор крон** — эллиптическая модель (полуширина 1.5/1.0/0.5 по высоте кроны), а не bbox: честно пропускает деревья в зазорах между домами, запрещая накрытие дверей.
- **Замена исходников deco_tree_*/deco_pine_*** вместо новых ключей — все сцены (деревня, лес, локации, пасека, развилка, бой) получили новые деревья минимальным диффом; при этом везде скорректированы масштабы (новые спрайты ~1.8× крупнее старых 56×72).
