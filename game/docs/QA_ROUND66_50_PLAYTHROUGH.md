## 🚨 НАЙДЕН И ЗАКРЫТ КРИТИЧЕСКИЙ БАГ ПРОДА (введён 66.48)

**CSP игры резала blob:-текстуры Phaser.** `img-src 'self' data:' не пускал blob: — а Phaser 3.88 грузит ВСЕ картинки через внутренний конвейер XHR→`createObjectURL`→`<img>`. Симптомы на проде с пуша 66.48 (7a02160): ~700 блокировок «Loading the image 'blob:…' violates CSP» → «Failed to process file: image tile_grass_0» → игра без текстур → циклический `TypeError: Cannot read properties of undefined (reading 'frame')` в `setCurrentFrame` → гард восстанавливал цикл, НПЦ/игрок деградировали, полный прогон падал 35 проверками.

**Почему не поймали в 66.48:** смоук 66.48 проверял только подъём Title-сцены (первые кадры прелоада), где блокировки ещё не успели проявиться на скриншоте. Урок: **после CSP-правок прогонять полный walkthrough, а не только Title.**

**Фикс:** `game/index.html` → `img-src 'self' data: blob:` (+ комментарий-объяснение; script-src/media-src без изменений). Ассерты в `test_round103` §5 (4 проверки). Подтверждено: после фикса 0 CSP-нарушений, полный прогон зелёный.

## 🧪 НАЙДЕН И ИСПРАВЛЁН ДЕФЕКТ САМОГО WALKTHROUGH (тест-инфраструктура, не игра)

Трассировка `ScenePlugin.start/launch` (addInitScript-перехватчик) показала двойные активные сцены: после секции 4 активными были **Village+Location/Village+Apiary**, кадры пасеки рисовались поверх леса/деревни.

**Корень:** легаси-клик «закрыть оверлей карты» по центру экрана (`page.mouse.click(640,360)`) после 66.34 (карта = полная сцена Fork с клик-зонами) попадал в **клик-зону деревни** → `travelTo('village')` стартовал фантомную Village; всё дальнейшее шло «в две сцены», программные `scene.start` из остановленных сцен оставляли хвосты (Apiary поверх Forest и т.п.).

**Фикс walkthrough_6627 (66.50):**
1. секция 4: клик-заглушка по центру убрана (оверея нет с 66.34);
2. секция 6: выход из пасеки КАК У ИГРОКА — телепорт игрока на выходной тайл (метка «◀ К ОКОЛИЦЕ» висит на TS*1.6=76.8px выше тайла, TS=48) + **клавиша E** («Нажмите E — Вернуться к околице», интерактив в этой сцене клавиатурный) → `leaveApiary()` → Fork; далее клик кнопки «🌲 Тёмный лес — прогулка» на карте;
3. секция 7: аналогично из леса → E → Fork → «◀ Вернуться в деревню»;
4. постоянный scene-трассировщик (`__sceneLog`) + дамп последних 30 переходов в итог;
5. пауза 7 c + двойной кадр перед скриншотом леса (headless троттлит rAF).

**Контроль единственности сцен (diag):** после леса `active: [{k:"Forest"}]`, после возврата `active: [{k:"Village"}]` — по одной активной сцене на каждом шаге. След переходов: `Location→Apiary→Fork→Forest→Fork→Village` — чистая цепочка.

Урок: **QA-скрипты должны ходить тем же путём, что и живой игрок (клики по UI-кнопкам/E-промпты), а не программными scene.start** — программные переходы из остановленных сцен создают состояния, недостижимые в реальной игре, и маскируют/создают артефакты.
