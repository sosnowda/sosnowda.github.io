## 1. ЗВУКИ (п.1)

**Аудит существующего:** шаги (`sfx_step` + `playStep` в Village/Forest/Apiary), двери (`sfx_door_open/close` при входе/выходе интерьеров), колокол (файл `sfx_church_bell` + полный синтез звона по службам `ChurchBells.js` с благовестом/трезвоном и тостами «🔔 Благовѣстъ…») — уже работали. Пробелы: **реки не было вообще**, дверь деревни молчала при входе, рыбалка была беззвучна.

**Сделано:**
- **НОВЫЙ `game/src/systems/RiverAmbience.js`** — процедурный шум воды (WebAudio, по канону ChurchBells — **без новых ассетов и без бампа кеша ассетов**): три слоя — низкий гул потока (brown-noise + lowpass 700 Гц с медленным «дыханием» LFO 0.08 Гц), «бурление» (bandpass 1900 Гц, телеграфные приливы 320–700 мс), мелкий плеск (bandpass 3600 Гц, тихо). Буфер сшит кроссфейдом — бесшовный луп. Плавный вход 1.2 с, затухание 0.6 с при уходе со сцены, уважает мьют SFX и `masterVolumeNode` (громкость из настроек).
  - Громкость по локации: **Река 0.9, Озеро 0.65, Мельница 0.45** (водяное колесо), остальные — тишина.
- **ПЛЕСК ВОДЫ** `playWaterSplash()` — одноразовый синтез (шумовой всплеск bandpass 1400→500 Гц + «бултых» тон 190→80 Гц) — при каждом забросе рыбалки на Реке (зимой лунка — тише).
- **Двери деревни**: `playRealDoorOpen()` при входе в дом по E и по клику (2 точки в VillageScene) — выход уже озвучен в InteriorScene.

## 2. ПЛАВНЫЕ ПОГОДНЫЕ ПЕРЕХОДЫ (п.2)

**Было:** `applyWeatherVisuals()` ставил затемнение и осадки мгновенно при входе в сцену; молнии жили рекурсивным `delayedCall` (утечка после кроссфейда); смена дня (новая погода) не применялась без рестарта сцены.

**Стало (Weather.js переписан):**
- **Fade-in 2.2 с** — затемнение (MULTIPLY-прямоугольник) и осадки (дождь/снег) плавно проявляются при входе в любую из 5 сцен (Village, Location, Forest, Apiary, Combat);
- **Кроссфейд при смене дня** — сцена сама опрашивает дату раз в 4 с: старое затемнение/осадки тают (1.4–1.6 с), новое погодное обрамление проявляется; живой тост «🌦 Погода меняется: <имя>» в пергаментном стиле колокольных плашек (не мешает HUD);
- **Молнии грозы исправлены**: TimerEvents собираются в список `flashEvents` — при кроссфейде/выключении сцены снимаются все, а не «бьют в пустоту»;
- сцены не тронуты (вызовы те же) — поведение включается автоматически.

## 3. СЕЗОННЫЕ РАБОТЫ (п.3)

**НОВЫЙ `game/src/systems/SeasonalWork.js`** — полевой календарь сентябрьского года (месяц 0 = сентябрь, как в RusTime/TimeSystem):

|---|---|---|

| май (8) | **ПОСЕВ** | борозды с рядами зелёных всходов |
| июнь (9) | **СЕНОКОС** | сочная трава в рост, копны сена по углам |

| декабрь–февраль (3–5) | Поле спит | снежный покров со снежными наносами |

- **РАБОТНИКИ-СТАТИСТЫ**: на поле выходят крестьяне по сезону (пахарь+работник / сеятель+сеятельница / косарь+гребёт сено / жнец+жница+отрок-вяжет снопы / крестьяне у жнивья; зимой никого). LPC-композиты собираются на лету из палитры (виртуальные npc-объекты, детерминизм по id — облик стабилен за игру). Клик — реплика по текущей работе («Коси, коса, пока роса!…»), запись в летопись.

- Кочки-твины качаются только на растущих фазах (сенокос/жатва) — пашня не «травится».
