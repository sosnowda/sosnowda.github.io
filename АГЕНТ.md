### Смоуки и проходы (браузер, 1280×720)

⚠️ **Головоломки headless (66.26, важно для новых смоуков):**
1. В headless-браузере игра рендерится ~0.5 FPS — эффект печатной машинки
   в диалогах ползёт (~0.5 символа/с). НЕ ждать допечатывания: клик по
   блокеру диалога (координаты ~640,60) вызывает `skipTyping()` и показывает
   текст целиком (см. `smoke_6626.mjs`, хелпер `skipTyping`).
2. ПЕРВЫЙ клик по плашке выбора при работающей машинке только ПРОПУСКАЕТ
   анимацию (`ui.js` wrappedCallback: `typingActive → skipTyping → return`),
   действие выполняет ВТОРОЙ клик. Хелпер `clickChoice()` кликает, пока
   текст выбора не исчезнет с экрана.
3. Клики по кнопкам считаются по позициям Phaser-объектов (обход контейнеров
   с накоплением смещений — см. `clickText` в `landing_shots.mjs`).
4. Headless-рендерер ИНОГДА падает («Target crashed») при переходе
   Village→Fork в ландшафте 844×390 — флейм среды, не баг игры: тот же
   переход в `mobile_check_6627.mjs` стабилен. При краше — просто
   перезапустить смоук; для диагностики есть `probe_map_6627.mjs` (ретраи).
5. Клик по кнопке ищется ПО ТЕКСТУ: на низких экранах околицы кнопка
   карты короткая («🗺 Карта», не «…местности») — искать подстроку
   «Карта» (см. `mobile_check_6627.mjs`).

## 3. Конвейер «обновить скриншоты на сайте»

```bash
# 1) сервер из корня репо (§1)
# 2) пересъёмка
node game/tools/landing_shots.mjs            # → /tmp/shots/01..09.png
# 3) замена изменившихся кадров + QA-кадры в game/docs
python3 game/tools/update_shots_6624.py
```
Скрипт сравнивает webp-vs-webp: кадр заменяется только если diff >0.5%.
Статичные кадры (титул/выбор героя) обычно идентичны — git их не трогает.
Если нужно обновить кадр ПРИНУДИТЕЛЬНО (например, приказ «обновить скриншот
карты») — удалить `assets/screenshots/05-map.webp` перед шагом 3, тогда
скрипт упадёт на сравнении и заменит; проще: заменить вручную
`PIL: img.save(..., 'WEBP', quality=85)`.

Alt-тексты кадров — в `index.html` (блок `screenshot-card`): при смене
содержимого кадра переписать alt (RU и EN-версия страницы `en/`).

## 4. Версии Service Worker (sw.js в корне репо)

- `CACHE_NAME = 'chronicles-ruthenia-vNN'` — ЛЮБОЕ изменение файлов игры
  (`/game/**`, скриншоты, index/styles) → бамп +1.
- `GAME_ASSETS_CACHE = 'game-assets-vNN'` — бамп только при изменении
  игровых ассетов (`assets/sprites|tiles|audio/…`), не исходников `src/`.
- В шапке sw.js — журнал версий (что и почему). Тесты 69–72 проверяют
  актуальную версию — при бампе актуализировать их.
