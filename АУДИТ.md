## 3. Лендинг (RU/EN)

**Сильные стороны**
- Семантическая разметка, `width/height` у всех `<img>` (нет layout shift), `loading="lazy"` для ниже-фолд скриншотов, webp q80–85.
- Alt-тексты содержательные (RU+EN), обновляются вместе с кадрами (66.40: карта «мельница рядом с пасекой», деревня «+база KT/кафтаны PB»).
- Двуязычность полная (отдельный `/en/`), попап-навигация с фокус-ловушкой (QA smoke_6631), таймлайн князей с `aria-pressed`, UTM-разметка внешних ссылок.
- Скриншоты — реальные кадры игры (пересъёмка автоматизирована: `landing_shots.mjs` → `update_shots_6624.py`, замена по порогу diff >0.5%).
- Вклад «Летопись разработки» — прозрачная история 40 итераций.

**Замечания (не критично)**
- У главного экрана нет `<link rel="preload">` для первого скриншота — мгновенная отрисовка и так быстрая (страница 62 КБ HTML + webp).
- OpenGraph/Twitter-карточки: проверить наличие картинок по абсолютному URL (соцсети требуют absolute URL) — рекомендация вне критического пути.

## 4. Игра — контент и механики

- **Мир:** деревня за частоколом (12 построек из пака «Fantastic Buildings», окна/трубы/дым — housesFX), 18 интерьеров, околица с полноразмерной интерактивной картой местности (13 клик-зон), 12 локаций развилки (озеро, мельница, пасека, погост, выпас, поле, река, 3 слоя леса, 2 тракта), Тёмный лес.
- **Персонажи:** 8 пресетов (архетип×пол) → 5 боевых обликов + **3 альт-героя** (Эстер→Баэнор, Лейанн→Охотница, Яромир→Сыщик — 66.39/66.40), листалка портретов «Портрет N/M», 43 буста.
- **Жители:** ~20 профессий с индивидуальными схемами одежды, детерминированная генерация внешности по зерну игры (базы 4 муж./3 жен., причёски 30/35, бороды 10, шлемы 10), перекраска по look, старение (50+ — выцветание), расписания (npcSchedules), блуждание, уникальность (без близнецов).
- **Только люди, строго исторично (66.39/66.40):** женщины — только длинные платья; брюки — только мужчины; зомби/чумной доктор паков PB — отбракованы по бустам; женская одежда PB/KT (штаны/табарды) не задействована.
- **Бой:** BRP-роллы, оружие по типам (удар/стрельба/кулаки), смена оружия, колчан, боевые облики паков с rim-light, у Яромира — честная анимация стрельбы.
- **Жизнь:** время (1 кл = минута, календарь 1462), дни недели, погода с приметами, сезоны работ, рыбалка по сезонам, ночь/запоры/ночной стук, вор с наводками и эскалацией, репутация, свадьбы, наследование знаний свидетелей, колокола, пожертвования церкви, мини-игры (пасека — уход за ульями, охота).
- **UI/UX:** RU/EN, мобильные виртуальные контролы (390×844 и 844×390 проверены), F1-справка, туториал, регулятор движения (?reduced-motion), «Вернуться на сайт».

## 6. PWA и кэширование

- `sw.js`: network-first для HTML/CSS/JS, cache-first для ассетов; два кэша: `chronicles-ruthenia-v90` (сайт) и `game-assets-v35` (ассеты) — бампятся при каждом изменении соответствующих файлов; журнал версий в шапке (v45…v90 — полная история).
- Офлайн-режим работает (кэш-первый ассеты); обновление — skipWaiting + активация.
- Совместимость сейвов соблюдена во всех итерациях: ключи `player_composite`/`npc_lpc_<id>` не меняются, новые поля героя (bustKey/battleLookKey) аддитивны.

## 9. Приватность и безопасность

- Бэкенда нет: всё статика, сейвы — localStorage игрока; сборов данных игрой нет.
- Внешние сервисы: Яндекс.Метрика на лендинге (транспортные 503/ERR_CERT в песочнице — шум, на игру не влияет).
- Google Drive используется только как источник ассетов на этапе сборки (в прод не попадает).
- PAT владельца — в `~/.git-credentials` локальной машины (не в репо); рекомендация: periodic ротация токена.

## 10. Риски и рекомендации

1. **Среда CI/песочниц:** headless-рендерер убивается по OOM на «тяжёлых» сценах (~5 с деревни) — это ограничение песочницы, не кода (прод стабилен). Рекомендация: для регрессов в CI держать `--no-zygote --no-sandbox` и ретраи (уже задокументировано в АГЕНТ.md).
2. **Мобильные шрифты карты:** подписи не масштабируются с картой — после 66.40 все 15 подписей разведены (проверено на 390×844 и 844×390); при добавлении новых подписей — сверять по mobile_check_6627.
3. **Вес аудио (13 МБ)** — на медленных сетях первый офлайн-прогрев дольше; можно перевести редкие треки на lazy-cache (низкий приоритет, кэш-первый уже сглаживает).
4. **OG-картинки** лендинга — убедиться в абсолютных URL (косметика).
5. **Технический долг конвейеров:** старые make_*-скрипты сохраняются по итерациям (воспроизводимость) — периодически помечать «исторические» комментарием, чтобы не путать с актуальными (6640 — актуальный для мировых листов).
