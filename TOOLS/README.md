## Установка и запуск (разовая подготовка среды)

```bash
# 1. Node.js 18+ и Python 3 — должны быть уже установлены.

# 2. Playwright (глобально) — движок головного браузера для смоуков:
npm install -g playwright && python3 -m playwright install chromium
#    (если уже установлен — путь к модулю: /home/z/.npm-global/lib/node_modules/playwright/index.mjs)

# 3. Локальный сервер ИЗ КОРНЯ репозитория:
python3 -m http.server 8765 --directory .
#    ⚠ перед запуском проверь, что порт не занят СТАРЫМ сервером прошлой сессии:
#    ss -ltnp | grep 8765   → если слушает чужой PID — kill его (он отдаёт старые файлы!).

# 4. Смоук игры (второй терминал):
BASE_URL=http://localhost:8765 node TOOLS/game_smoke.mjs
#    Ожидание: «СМОУК OK» — старт нового старта 66.84 проходит, 0 JS-ошибок.
```

## Ключевые правила прогона (кратко — детали в AGENTS.md §10)

1. **Проверяй, ЧТО отдаёт сервер** (`curl … | head`) — порт мог остаться от старой сессии.
2. **Клик по кнопке диалога — дважды**: первый клик при активной печатной машинке
   только снимает печать (`skipTyping`), второй выполняет действие.
3. **Строка цели квеста (`◆ …`) — не кнопка**: в поиске текста её пропускать.
4. Лови и `pageerror`, и `console.error` (ошибки узлов диалогов идут в console.error).
5. НПЦ по распорядку уходят «на поле» — ночные проверки улицы дают ложные провалы.
6. Скриншоты складывать в `/home/z/my-project/download/qa_<patch>_live/`.
